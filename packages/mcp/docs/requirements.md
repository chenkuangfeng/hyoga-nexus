# MCP 包需求

`hyoga-nexus-mcp` 提供 MCP 客户端、OAuth 协议层、工具桥与服务端协议层。完整规格见 `openspec/changes/2026-11-08-mcp/specs/mcp/spec.md`（R1–R11），这里只记录包自身承担的需求。

## 客户端连接

- 支持 `stdio`（`command` / `args` / `env`）、`streamable_http`（`url` / `headers`）与 `sse`（含 `sse_read_timeout`）。
- 连接参数写入前校验：未知传输、缺必要键、URL 非 http/https、命令为空、header/env 值非字符串或含控制字符 / 非 ASCII / 首尾空白一律拒绝；同名 header 按大小写不敏感替换。
- 凭据引用（`credential_references`）在连接时由调用方解析；仍含未解析引用则拒绝连接，错误信息不回显凭据值。
- 发现超时 30 秒；HTTP 传输断开重连一次，stdio 不重试；stdio 会话按服务、作用域与事件循环键控复用，LRU 回收。

## 工具目录与命名

- 发现结果默认全部禁用，由平台按工具启用；未启用、已移除或服务停用的工具在执行前复核时拒绝。
- 注册名 `mcp_{服务名}_{工具名}_{sha256(server_id \0 tool_name) 前 8 位}`，先注册者保留；外部工具名在加载边界按 `^[A-Za-z0-9_-]+$` 清洗。
- 工具描述带外部来源前缀，输入 schema 为空时用空对象 schema；schema 清洗与渐进加载由调用方（网关）负责。

## 执行与错误

- `call` 返回结构化结果；服务端拒绝与输出 schema 不匹配分别给出「修正参数重试」与「不要改参数重试」的稳定错误码。
- 401 / 授权挑战按 HTTP 响应状态统一识别为 `McpUnauthorized`（不依赖响应文本），由平台刷新一次令牌后重试一次；之后仍失败按稳定错误返回，不把传输细节带入模型上下文。识别同样覆盖会话建立阶段（握手 POST 被拒）。
- 超时、取消与外置/截断沿用网关既有语义。

## OAuth

- 仅限 HTTP 传输；配置含 `scopes`、可选预注册 `client_id` / `client_secret`（字符串或凭据引用）、可选 `auth_server_metadata_url`。
- 授权服务器发现：先读 RFC 9728 受保护资源元数据，再读 RFC 8414 / OIDC 元数据；issuer 必须与文档来源同源；非 HTTPS（回环开发地址除外）拒绝。
- 未预置客户端时按 RFC 7591 动态注册；注册结果按（租户、服务）复用，客户端被拒时丢弃。
- 授权码 + PKCE（S256）；`state` 为部署密钥加密的短时载荷，回调只接受可解密且未过期的 state。
- 令牌按（租户、主体、服务）加密存储；30 秒余量惰性刷新；刷新被拒（`invalid_grant` / 过期）删除令牌并要求重新授权。
- 令牌、客户端密钥不落明文，不进入指纹、缓存、事件、日志或异常信息。

## 服务端

- `tools/list` 返回该 Run 当前授权可见的定义；运行令牌短时、单 Run、可撤销。
- `tools/call` 须走完整网关管线（授权、审批、守卫、审计），不信任快照或传入参数；协议层错误稳定且不泄漏资源存在性。执行通道依赖外部 Runtime 适配器（路线图第 4/5 步）。
