# 深色主题切换

## 状态

待确认。调色板基础（`apps/web/src/styles/tokens.css` 与 `element-theme.css` 中 `:root[data-theme="dark"]` 块）已实现但未接入任何入口，因此对现有界面没有影响。切换入口、偏好保存与全页面验收需要本提案确认后实施。

## 背景

`2026-11-02-weknora-parity-phase1` 与 `2026-11-02-web-shell-layout` 都把深色主题列为计划项，设置页"主题模式"下拉目前禁用，只显示"浅色"。WeKnora 的暗色色板（固定版本 `e1f9a6166`）已对照移植到 `tokens.css`，并完成了暗色对比度的初步审计：登录页在暗色下只剩禁用按钮一项低于 4.5:1。

## 范围

范围内：

- **切换入口**：启用设置页"主题模式"下拉，提供浅色与深色两个选项，选择后立即生效。
- **生效方式**：在 `<html>` 上设置 `data-theme="dark"`，所有颜色通过已有 token 切换，不引入第二套样式。
- **偏好保存**：保存在浏览器 localStorage（与语言、侧栏宽度一致），页面加载时在首屏渲染前应用，避免闪烁。
- **全页面审计**：在暗色下检查登录页、对话页、设置各页、管理页的文字对比度（≥ 4.5:1，禁用控件除外）与输入框、下拉、弹窗、抽屉的背景是否正确。
- **浏览器测试**：扩展 `tests/web/layout.mjs` 或新增用例，覆盖切换、刷新后保持、以及暗色下的窄屏布局。

范围外：

- 不改变任何 API、权限、数据模型或 Runtime 行为。
- 不做"跟随系统"自动切换（见决策 2）。
- 不引入新的组件库或样式方案。

## 需要确认的决策

1. **偏好保存位置**
   - 推荐：浏览器 localStorage。与语言、侧栏宽度一致，不需要后端改动，但换设备或换浏览器后不会同步。
   - 备选：账号偏好（后端保存，跨设备同步）。需要新增用户偏好 API、持久化与迁移，超出本次前端范围，需要单独提案。
2. **选项范围**
   - 推荐：仅"浅色"与"深色"两项。
   - 备选：增加"跟随系统"（`prefers-color-scheme`）。改动很小，但需要额外测试系统偏好变化。
3. **默认值**
   - 推荐：浅色。已有用户看到的界面不变，只有主动选择深色的用户才会切换。

## 验收

- 设置页切换后，当前页面立即切换主题，刷新后保持选择。
- 暗色下浏览器测试 8 组全部通过（与浅色相同的用例）。
- 暗色下的对比度审计在登录页、对话页、设置页均无非禁用控件低于 4.5:1 的文字。
- 暗色截图检查：输入框、下拉、弹窗、抽屉、Element 按钮与标签没有浅色残留。

## 影响文件

- `apps/web/src/layouts/SettingsDialog.vue`：启用主题下拉。
- `apps/web/src/i18n/locales/*.ts`：移除"计划中"文案，新增深色选项名称。
- `apps/web/src/main.ts` 或入口脚本：首屏前读取偏好并设置 `data-theme`。
- `apps/web/src/styles/`：已有暗色色板，视审计结果补充覆盖。
- `tests/web/`：补充主题切换用例。
- 文档：`apps/web/README.md`、`docs/` 中提到"仅浅色"的段落在实施时同步更新。
