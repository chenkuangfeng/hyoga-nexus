# 完成聊天页消息栏与输入栏操作

## 目标

欢迎页标题统一为“Hi，我是Nexus”，移除不可用的推荐问题区域。参照仓库内 WeKnora 前端 `e1f9a6166` 的消息操作栏与输入栏，为 Nexus 页面中保留的图标提供真实、可追溯的交互，不再用仅提示“暂未开放”的入口冒充已完成操作。

## 范围

- 消息操作：复制、从消息分叉、回滚到消息、加入知识库、打开产物、查看请求信息；仅在相应消息/资源具备条件时显示。
- 输入操作：智能体选择、联网搜索、图片和文件附件、知识库/文件提及、模型选择、推理强度、发送/停止。
- 所有运行选项必须随 Run 请求显式提交并写入 Run 配置快照；服务端按会话主体、空间、智能体绑定和资源权限校验，禁止仅靠客户端切换权限。
- 操作遵循 WeKnora 的加载、冲突、失败与成功反馈；Nexus 专有会话与 Run API 不依赖 WeKnora API。

## 非目标

- 不增加模型供应商或知识库后端类型。
- 不在未绑定或无权访问的资源上提供提及、读取或写入。
- 不降低当前 Run 的授权、幂等和审计要求。
