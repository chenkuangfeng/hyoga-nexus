# 规格：工具扩展

来源：`openspec/changes/2026-11-07-tool-expansion`（待确认，确认并实施后归档）。

## 需求

### R1 工具分组与开关
- 每个工具定义声明 `group`；目录、编辑器和门控从注册表读取，不另维护分组表。
- 工具组有两层门控：可用性（部署侧事实，不满足则工具不出现，并给出稳定原因代码）与智能体开关（`tool_groups_enabled`）。任何一层不满足，该组工具都不进入工具定义，直接调用返回 `tool_authorization_denied`。
- 开关只能收紧：通过门控后，每次调用仍须通过实时授权、访问级别、参数守卫和审批。
- `sandbox`、`web`、`collab`、`schedule`、`media` 组默认关闭；既有智能体版本不因本变更获得新工具。
- `BUILTIN_TOOL_NAMES`、注册表与分组声明保持一致，不一致时测试失败。

### R2 沙箱组
- 只有在部署启用（`[sandbox].enabled`）且最近一次隔离验收对当前镜像与配置通过时，`sandbox` 组才可用；否则工具不出现，不是返回错误。
- 验收覆盖资源限制、网络隔离、租户隔离、清理、崩溃残留与连通探测，结果持久化，API 与 worker 读取同一份。
- 模型只看到虚拟路径；越界路径（含符号链接逃逸）被拒绝；公开结果不含宿主路径。
- 沙箱默认无网络；网络只能由部署配置打开，打开后命令类工具风险升为 `destructive`。
- 命令有墙钟超时、输出上限，超时或取消时终止整个进程组；写入为原子替换；同一路径的写入串行。
- `/outputs` 下的文件在 Run 结束时登记为产物，下载走授权检查；授予与下载写审计。
- 沙箱可用时，`run_skill_script` 经同一后端执行。

### R3 调度
- 工具可声明 `concurrency(arguments)`，结果为 `parallel`、`exclusive` 或带 key 的 `serial`；未声明时沿用 `read_only` 且 `idempotent` 的现有判定，现有行为不变。
- 同 key 的调用串行，不同 key 可并行；结果与生命周期事件按模型顺序。
- 参数解析失败的调用按独占处理。

### R4 渐进加载与 schema 清洗
- 绑定工具的 schema 估算超过阈值时，延迟工具只列目录，经 `tool_search` / `tool_describe` / `tool_call` 使用；Run 内工具块不变。
- `tool_call` 展开为真实工具后执行完整网关管线；未绑定、被组开关过滤或未授权的工具不能经桥接调用。
- 发给供应商的 schema 经清洗副本，注册的定义不被修改；被改写的属性名在调用时还原。

### R5 Web 组
- `web_fetch` 对每一跳（含重定向）校验解析后的地址，拒绝回环、私网、链路本地与元数据地址；有协议、端口、大小与超时限制。
- 搜索与抓取的正文带外部内容前缀，并经注入扫描。
- 搜索后端可插拔；未配置后端时 `web` 组不可见。

### R6 Wiki 组
- Wiki 工具属于 `wiki` 组（子组读、编辑、问题），不属于 `base`；仅当智能体绑定了 Wiki 类型知识库时出现。
- 读为 `read`；写、替换、改名为 `write`；删除为 `destructive`。

### R7 协作与定时（阶段 G，实施前补全）
- `delegate_task` 的子 Run 工具集是父级的子集，不继承 `collab` 组，审批冒泡到父会话，预算从父级扣除。
- `cronjob` 创建的任务无人值守运行，不得使用需要审批或询问用户的工具；提示入库前扫描；每用户有数量与频率上限。

## ADDED Requirements

### Requirement: 命名沙箱档位支持远程执行
部署 SHALL 支持本地、SSH、bwrap、Docker 和 HTTPS 托管档位。远程执行 SHALL 验证服务身份与工作区可见性，保持虚拟工作目录、超时、输出上限与 Run 产物登记语义。远程后端不支持的能力 SHALL 明确返回不可用状态。

#### Scenario: 选择已通过验收的远程档位
- **WHEN** 智能体选择已启用并通过远程验收的档位
- **THEN** 命令在远端执行，文件工具和产物登记使用该会话的共享工作区

#### Scenario: 企业管理员查看沙箱配置
- **WHEN** 企业管理员打开沙箱配置详情
- **THEN** 系统展示档位参数和验收报告，且不返回凭据

### Requirement: 托管执行有界传输与恢复
供应商适配器 SHALL 只传输当前会话文件与技能，拒绝越界、链接、特殊文件及超配额快照。命令输出 SHALL 在采集期间限制内存。请求重试 SHALL 不重复执行已登记命令。网关重启 SHALL 回收未结束实例，创建结果未知时通过请求元数据发现实例。验收 SHALL 绑定执行节点和模板策略摘要。

#### Scenario: 云实例无需共享卷
- **WHEN** 普通供应商模板执行会话命令
- **THEN** 文件经供应商 API 往返，结果原子提交到原会话并进入原产物流程

#### Scenario: 进程在创建实例后崩溃
- **WHEN** 网关从同一状态目录重启
- **THEN** 网关发现并销毁遗留实例，不重放命令

### Requirement: 供应商配置和系统限额
平台管理员 SHALL 能在管理端维护托管供应商模板、域名、版本与加密密钥。未回收实例存在时 SHALL 拒绝修改供应商。Linux bwrap SHALL 支持运维预先委派的 cgroup v2 限额，Docker/bwrap SHALL 支持预先配置的 XFS 项目硬配额。控制器不可用时 SHALL 拒绝执行。

#### Scenario: 保存供应商配置
- **WHEN** 平台管理员保存模板或凭据
- **THEN** 网关加密保存凭据，并使原连接摘要失效

### Requirement: 沙箱配置可视化维护
平台管理员 SHALL 能在沙箱引擎界面新增、编辑和删除 local、SSH、bwrap、Docker、managed 档位。配置 SHALL 持久化并供新 Run 读取，按类型校验参数，拒绝竞争覆盖及删除已被智能体引用的档位。

#### Scenario: 添加沙箱配置
- **WHEN** 平台管理员在配置抽屉选择类型并保存有效参数
- **THEN** 系统生成稳定标识，列表显示名称及状态，智能体可按既有权限选择该档位

#### Scenario: 部署选择控制台默认档位
- **WHEN** 部署通过稳定标识引用控制台创建的默认档位
- **THEN** 合并共享注册后校验默认档位，缺失时拒绝加载，不自动改选其他执行环境

### MODIFIED Requirements

### Requirement: 企业管理员维护与默认本地引擎
企业 owner/admin SHALL 能维护现有共享沙箱配置、策略、连接、供应商及回收；普通成员和非成员 SHALL 被拒绝。无显式配置时 SHALL 默认启用 docker/local、允许开发模式 Local，默认选择 Docker。显式禁用、自定义档位、删除标记、Docker 隔离验收和智能体工具开关 SHALL 继续生效。

#### Scenario: 企业管理员维护
- **WHEN** 非平台管理员的企业 owner/admin 提交合法配置
- **THEN** 系统保存配置并记录审计，无须额外的平台管理员身份

#### Scenario: 未配置沙箱
- **WHEN** 部署没有显式定义沙箱
- **THEN** 默认注册 docker/local 并启用，Docker 等待验收，Local 仅开发认证可执行
