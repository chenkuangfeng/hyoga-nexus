# 记忆检索质量样例

`recall_quality.jsonl` 是检索与事实身份评估集，不含真实用户数据。每行定义一个查询、候选条目和预期行为，供后续检索评估器或人工复核使用。

评估至少记录：

- Recall@5 / MRR：相关记忆是否进入前五及排序位置。
- 错误注入率：不同环境、属性或范围的记忆是否被错误带入。
- 错误更新率：只因主题或语义相似就更新既有条目的比例。
- 按需工具准确率：无关问题不触发搜索；需要历史事实时先搜索再读取。
- 删除抑制率：被拒绝或删除的内容不得重新召回。

`memory.search` 审计已记录关键词候选数、最终命中数及向量候选数。调整向量阈值或融合权重时，应在这组样例与新增的真实脱敏评估样本上对照，而不是只看单条会话。
