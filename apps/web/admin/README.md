# @nexus-web/admin

企业管理后台 Vite 应用，base 为 `/admin/`，与工作台独立构建。当前提供登录、强制改密、管理外壳、企业切换、权限导航、企业信息、角色与权限、审计日志、企业策略、成员邀请、加入申请审批和部门组织页面，其他管理业务仍待迁移。

`src/router.ts` 刷新服务端成员身份，管理外壳按当前企业的 `entries` 显示管理入口状态；缺失管理入口时显示无权限。共享登录与改密来自 `@nexus-web/core`，不导入工作台。后端接口仍负责每次请求的真实授权。未知路径使用公共 404 页面，不再显示为管理首页。邀请和无企业身份的开户流程跳转到员工应用，并保留原始查询参数。

管理端主框架不提供返回工作台或关闭入口。邀请/开户转交在开发时使用同主机 5173 端口，生产部署使用同源根路径。API 使用部署前缀下的 `/api/v1/`，不附加静态页面的 `/admin/`。

在 `apps/web/` 运行 `pnpm dev:admin`（5174/admin/）、`pnpm --filter @nexus-web/admin build` 、`pnpm --filter @nexus-web/admin test` 或 `pnpm --filter @nexus-web/admin preview`。产物为 `admin/dist`。完整页面与菜单权限实现见企业化提案 E2.5。

## 界面布局

企业管理主框架对齐员工工作台 `menu.vue`：左侧 Nexus 品牌、图标导航、折叠按钮，展开宽度 260px，折叠宽度 48px；窄窗口展开宽度为 220px。菜单区独立滚动，登录用户固定在左下角，展示头像、企业和用户名，点击后可切换所属企业或退出。两个应用独立，主框架没有返回工作台入口。

折叠偏好使用 `nexus.admin.sidebar.collapsed` 本地键，与工作台互不影响。折叠时菜单保留图标、可读名称和悬停提示。账户弹层支持 Escape、外部点击关闭及焦点恢复，切换企业期间禁止重复切换，并沿用身份校准、权限重读和旧作用域清理。导航图标使用管理端本地 SVG sprite。

业务页面继续使用公共设置标题、工具按钮、表格边框和标准设置行，常规内容内边距为 40px/48px，成员列表为 20px/28px。主题令牌及 TDesign 覆盖样式来自 core。管理外壳在 admin 内编排，不依赖工作台会话与资源状态；两个应用不互相导入。

## 企业策略

登录后进入概览，有 `policy:manage` 时显示「企业策略」，地址 `/admin/policy`。策略包括个人智能体自建范围、个人模型、对外共享、个人企微机器人、微信与 QQ 渠道以及会话保留天数。保存前需确认；关闭自动清理会显式提交 `retention_days: null`，只发送变化字段。策略收紧可能停用个人渠道，保留天数可能触发不可恢复的内容清理，页面会说明后果。

部门范围从当前企业的组织接口读取名称；需要 `org:manage`。没有该权限或部门加载失败时保留已有范围，其他策略仍可按权限编辑，不要求输入内部 ID。有效的管理端成员可通过地址只读查看策略；写操作始终要求服务端授权。

每次受保护导航先作废旧权限，再刷新 `/auth/me` 与当前企业 API 权限。切换企业或账号、权限失效及退出时立即清理旧页面；旧请求及确认弹窗不能写入新作用域。企业列表只包含当前账号的成员身份，不列出其他企业。企业信息、角色、资源、企微配置、渠道审核等页面尚未接入。

代码：`src/AdminLayout.vue`（布局与切换）、`src/stores/context.ts`（作用域与权限）、`src/views/EnterprisePolicy.vue`（策略）；公共客户端为 `core/src/api/enterprise-admin.ts`。

## 成员与邀请

具有 `members:manage` 时显示「成员与邀请」，地址 `/admin/members`。页面读取全部活跃成员，在前端按邮箱、用户名或显示名搜索并分页。待处理邀请分为人员邀请与有效链接，接受/拒绝/撤销后的人员邀请不显示为历史记录；不会虚构人员邀请的过期时间。

按邮箱邀请已有账号，对方登录工作台后可在邀请通知中接受，接受后才加入；为新邮箱创建账号时须填写用户名、临时密码与角色，账号直接加入并在首次登录改密。已有邮箱即使使用创建表单仍按后端行为发出邀请，不会覆盖密码。密码在提交发起、关闭表单、切换企业/账号、权限失效或卸载时清空，不写入存储。临时密码由管理员通过安全渠道单独交给本人。

邀请链接可指定 `admin`、`contributor`、`viewer` 和 1–30 天有效期，任何已登录的持有者可按该角色加入；管理员可复制或撤销。链接只保留在当前页面内存，离开作用域后清空；响应必须是已知的 `/join?token=...` 路径，复制时按开发员工端口或生产同源地址生成完整链接。

基础角色修改、移除、撤销邀请均需确认。拥有成员管理权限后，涉及 `owner` 的操作还须调用者为 owner；最后一名 owner 不可被降权或移除，后端在事务中复核。对自己的变更完成后，刷新身份及当前企业权限。成员与邀请列表各自保留加载失败反馈，失败的一侧不清掉另一侧成功的数据。

当前仅列出活跃成员，移除会撤销企业成员资格并保留账号，不等同于停用。后端尚无独立停用/恢复接口，加入申请审批已接入下方标签页；独立停用/恢复继续保留在 E2 任务中。

代码：`src/views/members/MembersPage.vue`（列表和表单）、`useMemberAdministration.ts`（请求、权限、确认与状态隔离）；公共 API 位于 `core/src/api/enterprise-members.ts`。剪贴板能力抽到 `core/src/utils/clipboard.ts`，工作台原路径继续转导出，保持原契约。

## 加入申请审批

在 `/admin/members` 的「加入申请」标签页查看待审批申请，支持搜索和分页。申请只在打开该标签时加载，离开标签后清理表单和在途结果。具有 `members:manage` 才能读取和审批；批准需要选择当前企业的启用部门和 `admin`、`contributor`、`viewer` 之一，不能授予 owner。

部门选项显示组织路径，以区分同名部门，通过 `org:manage` 授权的组织接口读取。没有组织管理权限、部门读取失败或没有启用部门时，批准入口禁用并显示说明，拒绝仍可使用。尚无可选部门时，具有组织管理权限的管理员可通过「部门组织」（`/admin/organization`）创建或启用部门，再刷新审批选项。

批准表单会说明加入的企业、部门和角色，确认后发送；成功会从待审批列表移除，并重新读取成员列表。拒绝须填写 1–500 字符的非空原因，确认前提示后端的 7 天再次申请冷却期。服务器报错时保留当前表单及申请，供核对或刷新，不伪造审批结果。

切换账号/企业、权限失效、刷新、关闭表单或离开标签页使旧操作失效；提交中防止重复请求并暂时禁用关闭按钮。申请读取失败不展示成功空态。页面只显示待处理申请，不提供后台尚无列表契约的审批历史。

代码：`src/views/members/JoinRequestsPanel.vue`；审批客户端和运行时校验复用 `core/src/api/enterprise-members.ts`，部门读取复用现有公共客户端。


## 部门组织

具有 `org:manage` 时显示「部门组织」，地址 `/admin/organization`。左侧按层级选择节点，右侧显示完整路径、状态、来源及直接关联的活跃成员；人数不包含子部门。支持首次创建根部门，创建手工子部门，手工节点重命名、移动、启用/停用与删除。根不能移动或删除，父节点选项排除自身及子树；移动、状态切换和删除均需确认。删除要求无子节点、无成员关联，历史成员关联仍可能使后端拒绝。

分配候选人员还需要 `members:manage`，只能选择当前企业读取到的活跃成员。没有该权限时仍可查看和维护手工部门的已有归属。一个成员可以关联多个部门；首次分配由后端自动设为主部门，页面以刷新结果为准。改设主部门和移除关联需确认；移除部门关联不会撤销企业成员资格。仍有其他部门关联时，须先改设主部门才能移除现主部门。

接口 `source=wecom` 的部门在本页禁止修改节点和成员归属，启用节点下仍可新增手工子部门。此限制目前由界面执行，通用组织写接口尚未按来源强制只读；树接口也未提供混合手工根节点的同步标记和成员关联来源，因此本页不能识别所有同步归属。服务端来源保护、同步状态与配置页面仍属后续任务，不能将本页作为同步数据不可修改的服务端保证。

树、候选人员和所选部门成员分别反馈失败。成员未读成功时禁止分配或删除，树失败不显示为可创建根的空组织。切换部门、企业、账号、权限或离开页面后作废旧响应、表单及确认。代码位于 `src/views/organization/`；公共客户端为 `core/src/api/enterprise-organizations.ts`。


## 企业信息

当前企业 owner 可进入 `/admin/enterprise`，读取名称、描述、状态与创建时间，修改名称和描述，或删除企业。名称为 1–160 字符，描述最多 500 字符；仅提交变化字段，空描述会清除原内容。删除须输入当前企业名称，服务端仍会拒绝存在关联共享空间等冲突。成功后清除身份及管理上下文，在 admin 登录页重新登录；不会跳转工作台。

读取失败提供重试，保存失败保留草稿，删除失败保留确认窗口。切换企业、账号、角色或权限代次时清空旧表单、快照与确认，旧响应不得写入新作用域。客户端校验详情类型与企业 ID，授权始终由后端复核。

现有详情接口不返回企业编码，本页不将内部 ID 当编码展示。编码接口与工作台旧管理入口清理仍待 E2.5.3 后续任务。代码为 `src/views/EnterpriseInfo.vue` 与 `core/src/api/enterprise-info.ts`，参考固定版本 WeKnora 的 `TenantInfo.vue` 设置行和删除确认流程，按 Nexus 既有契约实现。


## 角色与权限

具有 `roles:manage` 的成员可访问 `/admin/roles`，搜索角色、查看内置角色、创建自定义角色及编辑自定义角色的菜单和操作权限。权限选项读取服务端目录和当前操作者有效授权，只能授予操作者已有的权限；已有超出自身范围的授权可移除，全部移除后才能保存。菜单可见性不代替操作授权。名称为 1–64 字符，内置角色不可编辑，现有接口不支持角色改名或删除。

额外拥有 `members:manage` 时，可按可读成员名分配或撤销角色，owner 已有全部权限，不作为新增候选。已分配项不能重复分配；分配与撤销不改变成员基础角色。成员区读取失败不影响角色维护，但禁止成员授权操作。角色写入及分配/撤销前显示确认，成功后重新校准身份和权限，撤销自身管理权后立即清除管理内容。

刷新、关闭编辑、切换账号/企业/权限代次及卸载使旧表单和确认失效，迟到请求不得覆盖新作用域；写入失败保留草稿并可重试，写入成功后的权限刷新失败单独反馈。页面为 `src/views/roles/RolesPage.vue`，状态编排在 `useRoleAdministration.ts`，公共客户端为 `core/src/api/enterprise-roles.ts`。角色到企业智能体的使用授权见下文；工作台旧管理入口清理仍留在 E2.5.3 后续任务。


### 按部门批量分配角色

角色页下方提供部门分配区，需要角色管理、成员管理和组织管理权限。部门按完整路径显示，停用节点不可选择；角色仍限制为操作者可授予的范围。组织读取失败不阻断角色维护和单成员分配，通过页面刷新可重试。确认会说明所选部门及角色，只分配当前部门直接关联的活跃成员，不含下级；owner 和已有分配跳过，未来新加入部门的成员不会自动继承。

完成后按服务端实际数组显示新增人数及已有分配跳过人数，owner 不计入这两项。重复提交不创建重复分配；空部门返回零人。部门选择、旧确认和迟到结果随企业、账号或权限变化失效。现有 POST `/tenants/{id}/org-units/{unit}/role-assignments` 同时复核 `members:manage`、`roles:manage` 及目标角色权限子集，不依赖前端过滤。页面额外需要 `org:manage` 读取组织树。


### 角色到企业智能体使用授权

角色页提供独立的企业智能体授权区，读取当前可见的企业资源和角色授权，可设置“查看”“运行”，取消全部选项可撤销所选角色在该智能体上的授权。保存前显示角色、智能体和将替换的权限，空数组撤销另有明确提示。角色本身的内置标记不阻止使用授权分配，沿用后端契约。

候选受现有可见性、发布状态和模型权限过滤，并非企业完整目录；不显示个人资源。可见不等于有权授予使用，后端仍复核操作者持有的每项权限及知识库绑定范围，拒绝时保留草稿。列表无法解析的既有角色/智能体授权提示数量，不冒充零授权，也不自动删除。撤销仅影响当前角色，成员可能通过其他角色、部门或成员授权继续访问。

候选与授权读取失败时本区禁止提交，可独立重试，不影响其他角色管理区。切换选择、企业、账号或权限代次使旧确认失效；写入成功复用身份/权限校准，失败保留选择和权限。实现为 `AgentRoleGrantsPanel.vue`，类型化客户端位于 `core/src/api/enterprise-roles.ts`；沿用现有 GET agents、GET agent-grants 与 PUT role/agent grants，不改变后端授权规则。


## 审计日志

具有 `audit:read` 时可进入 `/admin/audit`，读取最近 100 或 500 条审计元数据，在已加载记录内按动作、结果、操作者 ID 或目标筛选，查看文本化元数据详情。列表无服务端游标/全量检索，不伪造总数、操作者角色、请求路径或审计正文；未知动作与结果保留原值。读取失败可重试，空结果与筛选无匹配分别提示。

日期导出沿用既有 JSONL 接口，按 UTC 自然日含首尾，开始不晚于结束且日期差最多 366 天。认证请求层取得 NDJSON Blob 后交由浏览器下载；文件包含服务端哈希链，导出操作自身被审计。这里不提供正文查看功能，`audit:read_content` 不能替代 `audit:read`。

切换企业/账号/权限代次或离开页面后，旧列表、详情与导出响应失效，不能下载旧企业文件；导出失败与列表失败分别反馈。页面为 `src/views/audit/AuditPage.vue`，编排在 `useAuditAdministration.ts`，客户端为 `core/src/api/enterprise-audit.ts`。工作台旧成员治理页已移除，成员/审批/审计由管理端承接，个人成员身份与退出由账户资料承接；其他管理配置迁移仍待后续。

## 企业智能体

`/admin/agents` 按服务端 `enterprise_agents:manage` 控制菜单和操作。列表筛出当前企业可见的企业智能体，支持名称/描述搜索；受既有列表接口的发布状态和模型访问过滤，不能视为企业完整资产目录。个人智能体不会进入本页。角色使用权限继续在角色页分配，只有 `roles:manage` 时提供入口。

创建通过既有 `/tenants/{id}/admin/agents` 写入企业归属，编辑与工作台共用 `core/src/components/agent-editor/NexusAgentEditorModal.vue`，保留基本信息、提示词、模型、工具、技能、知识库、沙箱与运行参数。工作台默认仍创建个人智能体。企业编辑只提供企业知识库候选，保留候选列表未显示的已有绑定，最终绑定权限/受众范围由服务端检查。模型管理导航由应用接收事件；缺少 `models:manage` 时显示权限提示。

保存先写草稿再发布不可变版本；发布失败留在同一份草稿，重试更新而非重复创建。归档需要确认，停止新的运行但保留已有会话，不提供没有后端接口的恢复入口。切换企业、账号、管理权限变化和卸载会清理旧列表、表单与确认，并作废迟到的保存/发布链。部门/成员受众、渠道和试运行界面仍属后续工作。

## 企业知识库目录与管理员

`/admin/knowledge` 按服务端 `enterprise_kbs:manage` 展示当前企业可见的 enterprise 知识库，筛除个人库与其他企业共享来的库；结果仍受既有可见性规则过滤，不是完整资产目录。卡片提供库类型、可见范围、文档数和名称/描述搜索，按资源返回的 `can_manage` 开放管理员操作。

管理员接口沿用 `/tenants/{id}/admin/knowledge/bases/{kb}/maintainers`。成员姓名/邮箱选项来自现有活跃成员列表；读取名单需要 `members:manage`，没有权限或读取失败时禁止新增选择，仍可查看、撤销已有管理员。已有管理员不重复出现在新增选项中。指定只授予内容维护，不授予设置、可见范围、删除或共享管理；撤销不改变企业管理角色等其他授权来源。每次写入先确认知识库和成员，失败保留目标和选择；撤销成功而重读失败单独反馈。企业、账号、权限、目标变化或卸载使旧查询、确认和结果失效。

创建与设置编辑共用 `core/src/components/knowledge-editor/KnowledgeBaseEditorModal.vue`，保留模型、向量、解析、分块、图像、音频、图谱、高级、存储、数据源、共享和活动等分区；共享面板允许维护已有共享并管理共享空间级别，新增/调整由服务端校验仅 tenant 可见知识库和 `external_sharing` 策略，策略关闭时仍可撤销已有共享。工作台通过薄宿主壳保持个人创建路径及原设置导航，core 不依赖任一应用。管理端创建走既有企业知识库接口，编辑前校验企业归属及 `can_manage`。创建成功后继续以同一 ID 读取并配置，读取失败可重试，不会重复创建。

编辑保存时在原生 settings 快照上合并完整编辑表单和未知扩展键，一次 PATCH 提交；已有库类型、存储后端与向量库绑定只读。可见范围支持 private/tenant；目录上的读取范围面板沿用现有整体替换接口设置成员和部门受众，设置非空受众后服务端将库切换为 scoped。部门列表需要 `org:manage`，成员列表需要 `members:manage`；缺少权限或读取失败时保留该类别原分配并禁用编辑。收窄受众导致智能体使用者失去读取权限时由服务端拒绝（`kb_in_use`）。清空受众不会自动扩大范围，可在设置中先显式恢复 tenant/private，再清理不再生效的受众。身份、企业、目标、权限变化及卸载会使旧编辑链失效。企业存储注册分别由 `/storage`、`/vector-stores` 和 `/graph-stores` 承接；没有服务端契约的解析设置继续显示说明，不跨应用跳转。

### 企业知识库内容维护

`/admin/knowledge/:kbId/content` 按文档库、问答库和 Wiki 库类型呈现对应内容。文档库支持分页搜索、上传、下载、删除、失败重试和重新索引；问答库支持条目搜索、分页及完整问答字段编辑；Wiki 库支持页面搜索、分页、新建、编辑和删除，并在更新时提交版本号处理并发冲突。所有请求使用显式企业路径和原有内容 API，入口再次核对企业归属与 `can_manage`，服务端仍是最终授权边界。系统索引页和日志页不允许编辑或删除。知识库目录也提供仅对可管理资源开放的删除操作，确认明确说明访问失效和后台清理。标签/目录、分块预览、批量导入导出、Wiki 修订历史及共享空间端完整业务验收仍待 E2.8。

手机宽度（600px 及以下）首次加载或从宽窗口进入时自动折叠管理侧栏，不保存这次自动收起为桌面偏好；同一手机宽度下仍可手动展开或收起。

## 企业模型目录

`/models` 仅对当前企业 `models:manage` 权限开放导航，管理当前企业共享 Provider、模型配置、不可变版本和按类型默认值。客户端显式使用企业路径并过滤个人 Provider；Key 只写不读，地址变更须重新提交。编辑模型会追加版本，停用保留历史并由服务端清理默认值。连接测试可能产生费用，只有聊天模型会向服务商发出请求。工具、存储等配置与工作台产物隔离仍待 E2 后续验收。


## 企业 MCP 只读连接

`/mcp-endpoints` 由 `tools:manage` 控制，管理企业对外提供的只读 MCP 端点及其工具、知识库白名单。知识库以可读名称选择，留空代表调用者可访问的全部知识库。端点令牌创建或轮换后只显示一次；关闭页面、切换身份或撤销令牌后，页面清除明文。服务端继续在每次调用时校验令牌、端点状态和范围。

`/mcp-services` 管理企业接入的 MCP 客户端服务、连接发现、逐工具启用、风险级别和调用审批要求。风险降低操作需要确认，服务端保留观察到的风险并计算最终生效级别。编辑器与工作台工具箱共用 core 实现；工作台可查看服务目录，管理操作由 `tools:manage` 和服务端再次校验。工具目录刷新后新发现工具默认关闭。

## 企业文件存储

`/storage` 按 `enterprise_kbs:manage` 提供当前企业文件存储目录，列出内置后端和企业配置。当前服务端仅实现 `local` 提供方；可新建本地目录、测试已保存后端及删除自定义配置。配置路径不会在列表回显。服务端可能依据部署策略拒绝企业配置本地路径；被知识库引用的后端不能删除。编辑、默认后端选择和未保存配置测试尚无 API，不在页面提供。

代码位于 `src/views/storage/StoragePage.vue`，运行时校验客户端位于 `core/src/api/enterprise-storage.ts`。管理页权限由前端控制显示，创建/删除仍由服务端管理角色校验。

## 企业向量库

`/vector-stores` 按 `enterprise_kbs:manage` 提供企业向量库目录、动态配置、保存配置编辑、草稿/已保存连接测试和删除。表单只开放能力目录中 `available` 的引擎，计划项只展示为不可操作状态；未验证的已实现引擎会明确标记。密钥由服务端脱敏回传，更新保留其掩码以沿用已有密钥；本地 SQLite 路径和私网地址仍受服务端部署策略限制。知识库正在使用的配置不能删除。

页面为 `src/views/storage/VectorStoresPage.vue`，类型化客户端为 `core/src/api/enterprise-vector-stores.ts`。服务端最终校验角色、目标地址及配置可用性。

## 企业图存储

`/graph-stores` 按 `enterprise_kbs:manage` 展示内置图存储和当前企业已登记项；现有可配置引擎 Neo4j 标为未验证，计划引擎不可操作。支持 Neo4j 登记、保存前连接测试、已保存连接测试及确认删除。密码只在当前表单内存中保存，列表不回显；服务端继续执行公网上游地址检查，知识库正在使用的图存储不能删除。

页面为 `src/views/storage/GraphStoresPage.vue`，运行时响应校验客户端为 `core/src/api/enterprise-graph-stores.ts`。服务端当前无编辑接口，因此本页不提供编辑操作。

## 企业微信绑定与应用目录

`/wecom` 由 `org:manage` 控制，展示企业绑定、回调凭据配置状态、通讯录同步状态及已有自建应用。企业 Corp ID 首次绑定后不可直接变更；回调 Token 与 EncodingAESKey 只写不读，空输入保留已保存值。支持请求立即同步、复制回调地址和应用主页地址，并明确标示扫码登录应用。该页面不展示或保存企业微信应用 Secret。

页面为 `src/views/organization/WecomPage.vue`，公共客户端为 `core/src/api/enterprise-wecom.ts`；服务端对配置、凭据和同步操作继续按 `org:manage` 授权。

## 企业智能体渠道审核

`/channels` 按 `enterprise_agents:manage` 展示当前企业渠道总览，并可按状态筛选；总览包含当前企业智能体渠道，包括成员个人智能体的渠道。待审核渠道可确认通过或填写原因拒绝，审批回执更新列表；渠道记录按稳定智能体 ID 关联当前可见名称，不展示内部 ID。服务端每次复核授权和待审核状态。

页面位于 `src/views/agents/ChannelsPage.vue`，渠道管理 API 位于 `core/src/api/enterprise-connections.ts`。

## 企业技能投稿审核

`/skill-submissions` 按 `tools:manage` 展示最多 200 条待审技能投稿。详情以纯文本显示技能内容、附加文件、最新扫描发现和与现有技能库版本的差异。批准前确认会说明技能进入企业库并可被智能体使用；若库版本已变化，页面阻止批准并提示刷新。拒绝要求填写 1–1000 字原因。客户端不渲染 Markdown 或不可信 HTML。

页面位于 `src/views/skills/SkillSubmissionsPage.vue`，运行时校验客户端位于 `core/src/api/enterprise-skill-submissions.ts`；服务端负责重新扫描、版本竞争检查和最终发布。

## 企业工具目录

`/tools` 按 `tools:manage` 展示当前企业可分配的内置工具、风险等级、审批要求和声明的副作用。管理员可以确认停用或恢复单个工具；停用只影响新建和编辑时的工具选择，已发布智能体版本保留现有绑定。实际调用仍受服务端工具门禁、审批和部署策略限制。

页面位于 `src/views/tools/ToolCatalogPage.vue`，使用 `core/src/api/nexus-agents.ts` 的目录与企业级内置资源开关接口。切换企业、账号或权限后，旧请求和确认框失效。
