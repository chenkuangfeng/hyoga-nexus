# 设计

- core 保持厂商无关契约；Docker 实现位于 sandbox；配置和装配位于 worker。
- 默认 disabled，不连接 Docker、不创建容器、不注册执行工具。enabled 不能代替隔离验收：未经目标环境验证继续拒绝执行。
- 每次执行独立容器，使用固定镜像摘要、非 root 用户、只读根文件系统、临时工作区；默认禁网、移除 capabilities、禁止提权，限制 CPU/内存/PID/输出/耗时，不挂载宿主秘密或 Docker socket。
- 调用前复核现有平台授权与能力策略；资源共享不等于高风险动作审批。未具备所需审批时，不面向模型注册执行工具。
- 超时/取消停止并删除容器，清理临时数据；结果未知的副作用保持 interrupted 语义，不自动重放。
- 产物后续使用平台 ID 与 Workspace/Run 归属，不返回宿主路径；完整产物能力另行确定存储、授权下载、大小配额与保留策略。
- 编码前核对固定版本 GenericAgent code_run、WeKnora sandbox 源码与测试，补充行为映射与兼容证据。
- 模拟后端验证控制逻辑；真实容器隔离与资源限制另记部署验收，不将模拟通过作为可启用依据。
