# API 需求

API 提供认证上下文下的空间、模型、智能体、会话、运行、事件和审计访问。

模型设置提供写入供应商和一次性 Key、多模型管理、默认偏好、测试连接、创建/发布 Native 智能体。返回可读错误、固定秘密掩码和凭据配置状态，不返回 Key。

连接测试只允许有管理权限的调用者，以最小请求验证所选模型的流式响应；可能产生少量费用，不能替代完整模型/工具验收。

智能体编辑器提供可选工具目录、智能体级生成参数（温度、思考强度）、归档与复制；归档后保留历史版本与会话记录，不再接受新会话与新运行。

## 企微组织同步来源

组织节点接口必须返回同步管理标记，归属列表与写入回执必须返回 manual/wecom/mixed 来源。手工修改同步节点或删除纯同步归属时返回冲突；既有 org:manage 授权继续生效。
