# 企业信息管理

### ADDED Requirements

#### Requirement: 企业信息读取与修改
管理端 SHALL 为当前企业 owner 提供基本信息页面，沿用现有 API 读取名称、描述、状态及创建时间，修改时仅提交变化的名称和描述。名称 SHALL 为 1–160 字符，描述最多 500 字符，空字符串清除描述。

- **WHEN** 保存成功
- **THEN** 页面与当前企业账户入口同步更新可读名称。
- **WHEN** 保存失败
- **THEN** 保留草稿并显示错误，允许重试。

#### Requirement: 删除确认和作用域隔离
企业删除 SHALL 要求输入当前企业名称确认，提交中禁止重复操作及关闭确认；最终权限和共享空间等冲突由现有服务端复核。

- **WHEN** 删除成功
- **THEN** 清除身份和管理上下文，在 admin 登录页重新登录。
- **WHEN** 切换企业、账号或权限代次变化
- **THEN** 清空旧快照、草稿及确认，迟到响应不得覆盖新作用域。

#### Requirement: 读取真实企业编码
TenantView SHALL 返回现有租户 code 字段（string/null）。管理端企业信息页 SHALL 展示和复制真实编码；缺失时 SHALL 显示未配置并禁用复制。不得以内部 ID 替代，不得通过本批接口修改或生成编码。

##### Scenario: 显示与复制编码
- **WHEN** 当前企业存在编码
- **THEN** 页面展示真实编码，复制反馈受当前账号、企业与页面代次保护

##### Scenario: 历史企业缺失编码
- **WHEN** 当前企业编码为空
- **THEN** 页面明确显示未配置，禁用复制，保留名称与描述的既有编辑流程
