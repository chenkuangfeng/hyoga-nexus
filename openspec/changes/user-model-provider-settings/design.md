# 设计

## 数据与模块
- platform 管理供应商、归属用户/空间、模型版本、加密凭据和默认偏好；core 不引入加密或供应商 SDK。
- API 处理一次性秘密写入与设置查询；worker 组合根解析受控凭据，保留 environment 类型解析兼容。
- 密文使用成熟加密库的认证加密方案；部署主密钥独立于数据库，由 API/worker 环境提供，不自动生成或写入仓库。缺少/错误主密钥明确失败。实现时锁定实际使用依赖并记录 ADR。
- 不在模型 options、事件、快照、日志、审计或错误中写入明文 Key；校验错误不得反射请求中的秘密。
- 新模型配置延续不可变版本机制；默认引用可用模型版本。编辑生成新版本，不暗中改变旧版本。Key 替换属于显式凭据轮换，旧配置引用的生效边界须在界面与文档说明。

## 权限与生命周期
- 用户身份来自服务端认证上下文，不接受客户端提供 owner 作为授权依据。个人资源须在模型列表、Agent 发布、Run 创建和实际执行处检查归属；不可通过共享 Agent 泄露个人凭据使用权限。
- 空间共享配置要求管理员权限；个人默认按用户与当前空间保存，空间默认由管理员维护，防止默认值指向无权资源。
- 删除采用停用策略；被默认引用时清除相关默认，被已有版本引用时保留可追溯元数据，后续执行明确返回不可用。活跃调用与撤销的边界通过测试和文档说明，不删除历史运行。
- 凭据只由被授权调用解析，审计记录对象与动作，不记录秘密。

## 测试连接
- 由服务器调用已保存供应商和选定模型，发送有界最小测试请求；不将浏览器作为供应商代理。
- 使用明确超时、输出上限、受控错误映射和权限/频率限制；界面说明可能产生少量模型费用。
- 防止自定义 URL 形成 SSRF：默认 HTTPS、禁止 URL 内凭据/查询/片段、拒绝回环/链路本地/私网/云元数据地址，不跟随重定向。请求连接和 DNS 校验需保持一致，避免只在保存时检查。开发私有端点如需支持，只能由部署端显式允许，不能由普通用户解除限制。
- 相同网络策略适用于实际 worker 请求，不仅用于测试连接。

## 界面
沿用 Vue 3/TypeScript/Element Plus 和既有视觉风格。用户设置中提供个人/空间范围选择、供应商列表、模型列表、默认标识和编辑表单。Key 输入不持久到浏览器存储，提交成功或离开时清除；替换需主动输入。提供空态、错误、加载、防重复提交、删除确认、键盘焦点与窄屏布局。

## 兼容与参考
编码前核对固定版本 WeKnora 设置/模型/凭据/权限源码测试和 GenericAgent 模型选择行为，记录映射。既有环境凭据、Agent 固定版本、Session 隔离、Run/SSE 和工具授权不得退化。
