## ADDED Requirements

### Requirement: 企业用量报表与月度限额
管理应用 SHALL 按 `models:manage` 展示现有企业 Token 报表，并提供企业、部门和成员范围的月度上限设置与移除。日期报表 SHALL 使用闭区间自然日；成员和部门分组选项仅在用户具备相应目录读取权限时提供。限额变更 SHALL 在提交前确认，展示输入/输出 Token 合计语义，并明确达到上限会阻止新 Run 提交但不影响进行中的 Run。页面 SHALL 不将 Token 用量表示为费用金额。企业、账号、权限或页面卸载后，客户端 SHALL 作废旧请求、确认及回执；服务端仍负责最终授权。

#### Scenario: 查询用量
- **WHEN** 管理员选择有效日期和可读分组维度
- **THEN** 页面读取既有用量接口并展示 Run、输入、输出及缓存 Token 数；空结果显示明确空状态

#### Scenario: 设置月度限额
- **WHEN** 管理员选择当前企业、可见部门或可见成员并输入正整数限额
- **THEN** 页面说明限额作用并要求确认，之后调用既有限额接口并刷新服务端限额和本月用量

#### Scenario: 移除月度限额
- **WHEN** 管理员确认移除一项限额
- **THEN** 页面通过既有接口移除限额并刷新列表；失败时保留当前数据并提示重试

#### Scenario: 授权范围变化
- **WHEN** 用户缺少成员或部门目录读取权限
- **THEN** 页面隐藏相应分组和新建范围选项，但仍显示服务端返回的限额并允许在服务端授权范围内移除

#### Scenario: 确认绑定原始数值
- **WHEN** 限额确认框打开后输入草稿变化或重复点击保存
- **THEN** 只允许一条确认写链，提交确认文案中原有的范围和 Token 上限；企业、账号或相关权限变化后旧确认不得提交

#### Scenario: 筛选草稿与已返回报表
- **WHEN** 用户改变分组但尚未执行查询
- **THEN** 已显示报表仍按原查询分组解释，迟到请求不得覆盖新查询

#### Scenario: 可选目录读取失败
- **WHEN** 成员或部门目录失败
- **THEN** 页面明确提示相应目录不可用，不提供该目录的新建限额范围，企业报表与限额继续可用
