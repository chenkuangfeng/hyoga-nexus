# 会话轨迹与产物标签

## ADDED Requirements

### 需求：会话页分标签浏览
工作台会话页必须提供对话、轨迹和产物三个顶层标签。产物列表必须在产物标签呈现，不再占用右侧常驻栏。嵌入式聊天维持紧凑对话布局。

#### 场景：查看会话产物
- **当** 用户打开已有会话并选择“产物”
- **那么** 页面在主内容区显示该会话产物、加载状态、失败重试或空状态

### 需求：检查 Run 执行轨迹
轨迹视图必须以持久化 Run 事件只读投影，按 Run 和事件顺序展示模型调用、工具调用、上下文压缩及终态信息。

#### 场景：查看模型用量
- **当** 用户检查一次模型调用
- **那么** 页面区分请求输入 token 估算、供应商返回的单次实际 usage（如有）与 Run 累计 token
- **并且** 缺少供应商 usage 时，页面不得把估算值标成实际用量

### 需求：保留执行审计兼容
Runtime 必须保留现有 RunEvent 事件流，并在模型开始事件记录输入上下文估算，在模型完成事件记录该次请求估算与 Run 累计 token。既有事件字段语义保持兼容。

#### 场景：读取历史 Run
- **当** 旧版 Run 事件没有新增估算字段
- **那么** 轨迹仍可展示已有事件和供应商 usage，缺失的值显示为不可用
