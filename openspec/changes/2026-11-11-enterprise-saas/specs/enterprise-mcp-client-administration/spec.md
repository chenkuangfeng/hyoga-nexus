## ADDED Requirements

### Requirement: 企业 MCP 客户端服务管理
管理应用 SHALL 按当前企业 `tools:manage` 权限提供 MCP 客户端服务配置、启停、连接发现及逐工具启用管理。服务列表、连接配置和工具目录 SHALL 使用现有企业租户 API；修改连接参数后服务端清除旧目录，新发现工具 SHALL 默认关闭。工作台与管理应用 SHALL 复用同一 MCP 服务编辑与工具目录实现，工作台成员视图保留只读行为。

#### Scenario: 无管理权限浏览
- **WHEN** 当前成员没有 `tools:manage`
- **THEN** 管理应用不提供 MCP 服务修改操作，工作台仅展示只读服务和目录信息

#### Scenario: 配置更新与目录发现
- **WHEN** 管理员新增或更新企业 MCP 服务，并发现服务端工具
- **THEN** 连接配置通过既有字段校验；配置改变使旧目录失效，新发现的工具全部关闭，管理员逐项启用后服务端才纳入可用目录

#### Scenario: 身份或企业切换
- **WHEN** 页面卸载、用户或当前企业改变
- **THEN** 旧请求不得覆盖新作用域的服务、工具或管理状态
