# 工作台旧部门管理隔离

## Requirements

#### Requirement: 部门写页面由管理应用承接
工作台 SHALL 移除旧部门管理页面及设置导航，不再随设置页加载其组织读写实现；已迁移的部门维护由独立 admin 应用提供。

- **WHEN** 用户访问旧部门设置书签或内部旧快捷调用
- **THEN** 工作台展示迁移说明，不请求组织数据或提供组织写操作，有当前企业 admin 入口时提供显式管理应用链接，否则说明权限不足。

#### Requirement: 独立应用与兼容书签
迁移说明 SHALL 不自动跨应用导航。开发链接使用当前主机的管理应用端口，生产尊重应用 base；admin SHALL 继续校准身份及组织权限。

- **WHEN** 当前企业或服务端 entries 变化
- **THEN** 链接可见性随当前企业更新；旧书签不会因为移除导航而丢失迁移说明。

#### Requirement: 保留未完整迁移能力
本批 SHALL 保留尚承载退出企业和审计等能力的旧企业信息/成员页，及共享空间、加入企业、企业切换和个人设置。完整管理依赖隔离仍为后续任务。
