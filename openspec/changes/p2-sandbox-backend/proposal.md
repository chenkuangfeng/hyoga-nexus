# P2 沙箱执行后端（待确认）

## 目标
按用户要求先实现沙箱代码，默认关闭，真实隔离环境验证留到后续；PostgreSQL 专项排在最后。

## 范围
- 在 packages/sandbox 实现 Docker 执行适配器，由 worker 显式装配，保留 SandboxPort。
- 默认不注册代码执行工具；配置启用与目标环境隔离验证均通过后才开放调用。
- 实现运行隔离、资源限制、超时/取消、清理、输出截断与稳定错误。
- 文件产物指运行生成的 CSV、图片、报告等文件。本提案仅预留产物边界，不将完整存储/下载界面自动纳入沙箱实现。

## 非目标
本轮不进行真实模型、Docker 隔离部署或 PostgreSQL 验收；不开放宿主 shell，不实现高风险审批或自动化。
