# 对话上下文装配验收

## 条件与范围

基线为 `c497eb9a` 的隔离源码快照，改造后运行相同安装依赖与脚本；均使用 20 段固定语料、45 次 Run 准备和脚本化模型。`assembly_benchmark.py` 在准备计时前收集循环垃圾，计时区暂停循环 GC，两侧条件相同，避免建库夹具的延迟回收污染准备耗时。该数字是平台微基准，不是生产端到端延迟、真实模型质量或供应商缓存命中。

原始结果：[基线](assembly-baseline.json)、[改造后](assembly-current.json)。运行：

```bash
.venv/bin/python evals/context-performance/assembly_benchmark.py --root /path/to/source --json /tmp/assembly.json
```

`--root` 指向被测源码目录；脚本显式优先加载该目录下的 Python 包。基线目录用 `git archive c497eb9a` 导出，不切换工作分支。

## 结果

| 指标 | 基线 | 改造后 |
| --- | ---: | ---: |
| 完成会话 | 20/20 | 20/20 |
| 模型输入总字符 | 59,351 | 59,351 |
| 准备 p50 | 22.22 ms | 25.44 ms |
| 准备 p95 | 45.66 ms | 48.52 ms |
| 连接占用 p50 | 21.92 ms | 25.13 ms |
| 请求视图装配 p50 | 0.043 ms | 0.046 ms |
| 规范化前缀摘要种类 | 2 | 2（逐项相同） |
| 准备 SQL 总数（45 次） | 1,873 | 1,943 |
| 准备 SQL p50 | 39 | 41 |
| 10k 历史实际物化行 | 10,001 | 1,001 |
| 10k 历史保留用户消息 | 1,001 | 1,001 |
| 10k 历史读取 p50（5 次） | 497.91 ms | 27.67 ms |
| 100 工具目录授权端口调用 | 100 次标量 | 1 次批量 |
| 1000 工具目录授权端口调用 | 1000 次标量 | 1 次批量 |

无外部 provider 的准备 p95 回退约 6.3%，在本变更的 10% 门槛内；小会话增加来源账本与检查的开销，不能宣称所有准备路径都更快。大历史的收益来自 SQL 过滤旧工具行，仍保留全部未摘要用户消息。无外部工作时读取与提交共用短事务；有外部 prefetch 时释放事务、连接与锁，提交前重新授权。连接占用数字来自无外部工作的固定语料；慢 provider 在事务外的性质由专项测试验证。规范化前缀摘要只涵盖 system 文本与 name/description/parameters，不等于供应商线协议字节或 cached_tokens。

工具目录端口规模测试使用无 I/O 授权替身，只证明调用次数，不能将其当成真实数据库耗时。该微基准的 1000 工具 CPU 装配由 1.96 ms 增至 15.55 ms，包含 schema 规范化 JSON 拷贝的隔离成本，不能以批量端口调用次数直接宣称总耗时下降。真实资源事实查询另由 `test_context_resource_batch.py` 验证：100/1000 个本空间资源分别为 3/12 次分批 SELECT，逐条判断不再发 SQL；工具执行不复用这些权限结论。

## 正确性与边界

- 新增装配、缓存隔离、插件角色/命名空间/并发/超时、session/run/step 生命周期、等待恢复、记忆失效、来源跨主体/空间、重试撤权、MCP 目录与风险更新、租约/取消、旧快照及迁移用例。
- 辅助摘要发送前也检查上下文权限；没有调整摘要算法和累计 token 预算策略。
- 新增 context.assembled 是有意的事件扩展，事件顺序基线同步记录；其余执行状态和工具结果顺序保留。
- 迁移在 SQLite 验证空库、已有记录、重复升级及降级；旧执行 Run 无完整来源时标为 legacy，只从模型输入隐藏，存储和授权审计仍保留。PostgreSQL 真实环境验收仍由平台迁移验收项负责。
- 分组回归：第一组 387 passed / 1 deselected；第二组五批依次 104、90、301、94、95 passed，最后一批另有 1 skipped（最后一批与上下文专项联合复测，共 133 passed / 1 skipped）；第三组 686 passed / 3 failed / 5 deselected；第四组 102 passed。按分组去重合计 1,859 passed、3 failed、6 deselected、1 skipped；不能将其描述为全量通过。新增上下文专项另跑 51 passed，包含溢出重试的引擎专项 33 passed。
- 已确认的既有失败共 9 项：沙箱编辑器 local 的 cgroup_root 校验（1）、local 后台命令不受支持（5）、远端 provider 取消清理（1）、工具组默认开关断言（2）。前 7 项在 `52469401` 源码复现，后 2 项在当前 HEAD `c497eb9a` 源码复现。本任务不调整沙箱或工具组默认值。
- 嵌入式 worker 批量回归发现的 SQLite 读锁升级冲突已修复：上下文写事务先取得写锁，再读取账本及校验租约。受影响完整批次与上下文专项联合复测为 133 passed / 1 skipped，保留原用例完成断言。

真实模型任务完成率、事实一致性、cached_tokens 和动态资料尾置的质量评测未执行。因此保留 v1 默认布局，不开启 v2，也不将脚本化成功视为质量验收。原提案的真实模型基线与归档任务继续保持未完成。
