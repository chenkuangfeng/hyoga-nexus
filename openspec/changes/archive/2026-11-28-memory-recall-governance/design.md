# 设计

## 1. 注入与召回策略

`budgets.memory` 增加 `profile`，仅显式为 true 时将已审核 Profile 注入模型；`recall` 改为自动逐轮召回开关，默认关闭。关闭自动召回不移除 `search_memory` / `read_memory` 工具，智能体仍可按需调用。会话索引快照只含有限条目目录，不含 Profile 正文；Profile 正文独立按当前 Run 设置生成，避免旧快照绕过关闭设置。

## 2. 事实身份与更新

记忆提议支持 `subject`、`attribute`、`scope` 与 `intent`。规则层将其规范化形成事实键，作为候选匹配和草稿的审计元数据；现有 topic、指纹、包含、冲突、相似逻辑保留为候选提示。只有显式目标 ID/base_version，或规范化事实键唯一匹配时才转为编辑；主题相同本身不再自动覆盖。提议更新须附来源证据；证据与来源消息 ID仍由服务器验证/关联。审核发布继续执行版本冲突保护。

## 3. 轨迹

`memory.used` 来源区分默认居民类别、`auto_recall`、`tool_search`、`tool_read`。上下文来源只显示条目标题、版本及必要来源，不伪装成模型请求；工具调用仍按真实工具消息显示。详情通过持久化消息和 Run 轨迹请求快照关联。

## 4. 检索质量

向量仍是当前发布版本的派生数据，关键词/向量排名融合保持现状。新增确定性 eval 样例覆盖同义检索、同主题不同属性、否定纠正、时效范围、删除后不再召回和按需工具读取。阈值调整须基于评测结果，不凭单例提高相似度阈值。

## 5. 持久化与兼容

提议新增字段用可空列追加迁移；旧条目字段为空时只按精确指纹、明确 entry_id 或人工选择处理，不用旧 topic 自动推断新的事实身份。Agent JSON budget 新键无数据库迁移。用户已有的会话快照继续只作为目录快照；居民类别依据当前 Agent 版本设置实时判断。

## 6. 配置职责

个人记忆页只保留数据管理和用户启用开关，不再显示提炼策略表单。智能体编辑器的独立记忆配置控制该智能体是否使用记忆、是否每轮召回、哪些类别默认注入以及自动提炼策略；现有空间和成员级禁用开关继续作为安全门，关闭后不删除已保存记忆。

空间管理员配置空间是否启用记忆、向量模型、检索和保留策略；这些规则在企业管理端维护，服务端按空间统一执行。智能体配置控制该智能体是否允许使用记忆、是否启用主动召回/Profile 注入、自动提炼模型与容量策略。部署级密钥、存储、供应商连接和硬性安全上限由平台运维配置。

迁移时保留已有成员级设置作为兼容默认值；Agent 显式配置优先，未显式配置的旧 Agent 仍读取原成员设置。新配置随 Agent 版本发布和回滚，不需要数据库迁移。

## 7. 智能体记忆控制与个人记忆列表

智能体编辑器把记忆配置作为模型配置后的独立导航区，包含记忆启用、自动召回和默认注入类别；基本信息区不再放记忆开关。个人记忆页保留 WeKnora 风格的状态标签页，仅提供记忆条目查看、审核、归档等数据操作。

记忆条目以 `fact`、`preference`、`personal_info`、`interest`、`task` 分类，旧 `memory`、`sop`、`profile` 值继续可读并映射为事实、事实、个人信息。上下文快照仅常驻注入 `preference` 与 `personal_info`（含旧 `profile`）；事实、兴趣、在办事项与 SOP 不进入每轮初始上下文索引，只能通过逐轮主动召回或 `search_memory` / `read_memory` 按需加载。Agent budget 中用 `context_kinds` 显式记载常驻类别，旧 `profile` 布尔值仅作为兼容输入。

个人记忆四个列表标签为生效中、待确认、自动提炼、归档；自动提炼复用当前主题跟踪数据，不另造一套持久化状态。

## 8. WeKnora 个人记忆页与 Agent 提炼策略

个人记忆页采用 WeKnora `frontend/src/views/settings/MemorySettings.vue` 的页面骨架：顶部个人启用开关与说明；列表标题区右侧提供添加、导出、整理和清空；下方以类别/状态标签筛选并展示内容，条目支持编辑和删除。Nexus 的条目版本、证据审核和软归档语义继续保留，删除操作将条目归档并保留审计版本。

自动提炼配置属于产生记忆的 Agent：`budgets.memory` 保存 `capture_enabled`、可选的提炼模型版本覆盖和 `capacity_policy`。后台在 Run 完成时从 Run 快照读取这些字段；空模型覆盖表示使用该 Agent 的主模型。未显式配置这些字段的旧 Agent 继续使用原成员级 `memory_capture_settings`，作为迁移期兼容默认值。发布 Agent 时校验提炼模型的空间授权和模型类型。个人页顶部个人开关仍是用户同意/禁用门；企业空间的记忆总开关是管理员治理门，两者不互相替代。
