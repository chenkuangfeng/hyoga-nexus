# Native：GenericAgent 源码迁移与 WeKnora 逻辑翻译

## Why
当前 Native 完成的是基础对话/工具闭环，并未完整迁移 GenericAgent。实际复现表明空响应、仅代码、未解析工具文本会直接成功结束；工作记忆、收尾、长期记忆/SOP、hook 上下文变换、多协议与恢复仍有遗漏。WeKnora 也包含成熟 Agent 引擎，不能只当资源平台参考。

用户要求严格保留两个项目所有逻辑细节，深度分析后复制/翻译迁移，同时参考模块结构，允许便利性扩展，日常配置默认放在用户前端。此要求已写入 AGENTS.md。

## What Changes
- 固定 GenericAgent `a9a36b4`、WeKnora `e1f9a6166`，维护全量来源索引和逐功能/分支差异表，逐项审查，复制经审查的 GA 实现，等价翻译 WeKnora Go 行为，保留来源/版权/许可。
- 以一个 Python Native 循环编排，恢复 GA completion/no_tool、done hooks、turn-end、工作记忆/历史锚点、工具协议、长期记忆/SOP、项目上下文与插件扩展能力。
- 翻译 WeKnora 的空/截断/重复响应判断、受控恢复、上下文摘要检查点、运行中输入、审批/挂起恢复和工具执行边界。
- 模型协议扩展到所需的 Chat Completions、Responses、Anthropic Messages 与文本工具协议，保留多模型路由、重试/冷却/回归主模型、usage/缓存的实际语义。
- 工具与 Handler 分模块迁移，保留生成器进度、最终结果及原参数兼容；补齐 ask_user 候选项与 checkpoint key_info 兼容。
- 记忆读取、整理、审核发布、索引同步和版本恢复成为完整独立能力；不把“有草稿接口”计为迁移完毕。
- 日常设置在前端维护，覆盖行为预设、模型参数/故障转移、预算/重试/压缩、工作记忆、项目/长期记忆、工具/技能/审批；持久化、版本、默认和个人/空间权限同步实现。
- 对知识/技能/MCP、协作/后台/定时、附件/产物/浏览器、多渠道/桌面等完整项目外围能力逐项建立实施或明确暂缓归属，不用“后续阶段”笼统删掉差异。
