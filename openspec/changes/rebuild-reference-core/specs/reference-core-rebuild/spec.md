## ADDED Requirements

### Requirement: 重实现必须由固定核心源码与测试驱动

平台与 Native 核心 MUST 基于固定 GenericAgent/WeKnora 的实际实现复制或等价翻译。每个迁移模块 MUST 在编码前完成来源、分支、依赖与原测试核对，并保留源版本/路径/哈希、目标实现、适配差异和可执行证据；MUST NOT 用概念重写、占位接口或模拟产品能力声称迁移完成。

#### Scenario: 模块尚未完成源分支核对

- **WHEN** 一个模块只阅读了 README、代表入口或部分测试
- **THEN** 该模块继续标记待深读，不进入已迁移/完整兼容清单

#### Scenario: 直接复用或等价翻译

- **WHEN** 模块使用上游源码或翻译其实现
- **THEN** 必需归属与适用许可随实际派生文件保留，来源/行为/测试映射可核验，不提交整个上游仓库

### Requirement: 类与业务职责必须按模块分布

系统 MUST 将领域实体、仓储事务、应用服务、运行编排、模型协议、工具执行、上下文记忆与审批恢复分开。主要业务类 MUST 有独立且明确的模块归属；__init__ MUST 仅承担导出，MUST NOT 把所有 ORM、服务或多个协议状态集中在同一文件。小型同领域 DTO MAY 就近组织。

#### Scenario: 平台实体与服务拆分

- **WHEN** 平台持久化与 Run 服务被重实现
- **THEN** 按领域加载唯一 metadata，旧导入仍可用，提交/领取/事件/取消/准备/持久化各有清楚边界

#### Scenario: 模型协议拆分

- **WHEN** 处理 Chat、Responses 与 Messages
- **THEN** 每种协议的请求、状态解码和响应转换独立，传输与 retry/routing/usage 不混进唯一大状态类

### Requirement: 核心执行语义必须显式映射

Native MUST 只有一个模型/工具循环，并实现已确认的 StepOutcome/no_tool/done queue、工作锚点、上下文管理、steer、并发屏障、生命周期和结束判断。原项目冲突 MUST 采用设计中明确的适配，不能隐式丢分支。

#### Scenario: 模型认为自然结束但仍有指令或收尾提示

- **WHEN** 收尾队列或结束边界有已授权且未消费的用户指令
- **THEN** 按持久顺序在预算内继续，不提前发业务成功终态，不重复已执行工具

#### Scenario: 只读工具与写入工具混合

- **WHEN** 一个批次包含可并发只读调用和写入/执行/未知调用
- **THEN** 前序读完成后执行屏障动作，后续读不能越过，结果按模型原序返回且单调用异常隔离

#### Scenario: 取消、空响应与输出截断

- **WHEN** Run 取消、模型持续空/重复或工具参数被截断
- **THEN** 使用独立有界保护与明确状态，取消不发额外模型请求，截断工具不执行，终态事件不能冒充成功

### Requirement: 上下文与恢复状态必须完整且可持久重建

系统 MUST 分别管理工作记忆、长期记忆/SOP、可读摘要与协议私有状态。压缩 MUST 保留合法工具交换与源记录，并提供有界溢出恢复。等待输入/审批 MUST 保存版本化快照、blocked index 和已完成调用记录，在其他 worker 恢复时复核当前授权。

#### Scenario: 模型上下文溢出

- **WHEN** 已确认的上下文上限错误或响应上限命中发生
- **THEN** 仅在允许的一次恢复内按实际压缩算法处理，计入预算，不反复付费压缩相同不可缩减历史，不重放已完成工具

#### Scenario: worker 重启后回答或审批继续

- **WHEN** 合法用户回答版本化挂起请求
- **THEN** 根据当前作用域/配置/授权重建并从阻塞调用继续，未知版本受控拒绝，已完成或副作用未知动作不得自动重放

#### Scenario: 协议签名与摘要分别存储

- **WHEN** 模型需要带签名或 opaque metadata 的历史重放
- **THEN** 使用所属协议/模型版本的合法原始材料，不以改写摘要替代签名内容，不向其他模型或无权主体泄漏

### Requirement: 动作授权必须区别于资源共享和单次审批

平台 MUST 分别校验资源使用权、单次动作决定和可记忆 ActionGrant。ActionGrant MUST 包含明确主体/空间/作用域、配置绑定、风险及失效规则，撤权和配置变化在恢复/执行点生效。

#### Scenario: 已记忆授权失效

- **WHEN** 主体撤销、授权过期、配置 hash 或风险发生不被覆盖的变化
- **THEN** 原记忆决定不再放行动作，重新进入合法审批且记录原因，不以 Workspace 角色或资源共享跳过

### Requirement: 重实现必须保留对外兼容和真实验收边界

替换 MUST 保留已确认 API、数据、版本、Run 幂等、SSE 游标、凭据保护及已发布模型终态规格。新增 schema MUST 使用增量迁移。未迁移/暂缓/环境未验收 MUST 分开记录，不恢复用户已删除的审查目录。

#### Scenario: 旧会话和导入路径

- **WHEN** 结构拆分和实现替换后读取旧 AgentVersion/Session 或导入旧公开入口
- **THEN** 仍遵守固定版本与现有表/约束，必要的快照升级有测试，不清库或静默丢数据

#### Scenario: 本地回归通过但生产环境未验证

- **WHEN** 只有 SQLite/模型 HTTP 夹具或部分原测试通过
- **THEN** 只能报告其实际证明范围，Go、真实供应商、PostgreSQL 和暂缓沙箱仍保留相应未完成状态
