## ADDED Requirements

### Requirement: 企业 MCP 客户端服务管理
管理应用 SHALL 按当前企业 `tools:manage` 权限提供 MCP 客户端服务配置、启停、连接发现、逐工具启用及风险策略管理。服务列表、连接配置和工具目录 SHALL 使用现有企业租户 API；修改连接参数后服务端清除旧目录，新发现工具 SHALL 默认关闭。工具策略 SHALL 支持显式风险级别与调用审批要求，降低风险时界面须确认，服务端继续保留观察风险并计算最终生效级别。工作台与管理应用 SHALL 复用同一 MCP 服务编辑与工具目录实现，工作台成员视图保留只读行为。

#### Scenario: 无管理权限浏览
- **WHEN** 当前成员没有 `tools:manage`
- **THEN** 管理应用不提供 MCP 服务修改操作，工作台仅展示只读服务和目录信息

#### Scenario: 配置更新与目录发现
- **WHEN** 管理员新增或更新企业 MCP 服务，并发现服务端工具
- **THEN** 连接配置通过既有字段校验；配置改变使旧目录失效，新发现的工具全部关闭，管理员逐项启用后服务端才纳入可用目录

#### Scenario: 风险与审批策略
- **WHEN** 管理员调整某工具的风险级别或调用审批要求
- **THEN** 请求经 `tools:manage` API 写入，降低风险需用户确认，界面依据服务端回执显示最终风险与待降级状态

#### Scenario: 身份或企业切换
- **WHEN** 页面卸载、用户或当前企业改变
- **THEN** 旧请求不得覆盖新作用域的服务、工具或管理状态
