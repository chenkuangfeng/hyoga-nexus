# Web 需求

Web 提供 Native 对话工作台、平台能力状态和用户设置。

企业管理端模型设置提供企业服务商与模型、按类型筛选搜索、密钥轮换、聊天连接测试、企业默认模型与用量管理。员工设置不提供模型配置；已有会话保持固定模型版本。

企业管理端提供智能体创建、编辑与归档，员工智能体页面只查看和使用；编辑器提供基本信息、系统提示词、模型与生成参数（温度、最大生成 Token、思考强度、最大迭代次数、模型调用超时）和工具选择。保存即发布新版本，已有会话不受影响。

Key 只用于一次性输入，不写浏览器持久存储、不回显；取消、提交结束或离开页面时清除输入。页面提供空态、加载、错误、操作反馈和停用确认，在桌面/窄屏与键盘下可使用。

员工的我的记忆支持审核、历史版本、恢复与归档；空间长期记忆规则在企业空间配置。运行参数与工具选择在管理端智能体编辑器配置，已发布版本保持固定；员工会话支持运行中追加指令与逐调用审批。

## 企业化工程边界

Web 分为公共源码包 `core`、员工工作台 `workspace` 与企业管理应用 `enterprise`。公共包不得依赖应用，两个应用互不依赖，共用接口契约、认证、企业切换和基础偏好。工作台在左下角账户菜单的「设置」下为当前企业空间 owner 和管理员提供「企业管理」。入口以服务端返回的 `entries` 为准，进入同源 `/enterprise/` 时沿用会话并重新校验资格。业务重构与验收范围见企业化提案 E2，真实外部服务与完整业务验收由 E2.8 跟踪。

自助注册只创建企业，邀请注册加入邀请所属企业；受保护页面恢复已有令牌，未登录时进入登录页，不使用桌面自动开户。强制改密页要求有效身份，临时密码账号完成改密后才能进入工作台。平台管理界面已删除，未知或已删除的地址需提供清晰提示。员工工作台与企业管理应用是独立应用，不提供跨应用返回菜单。

智能体维护者通过智能体自身的渠道页管理 IM 渠道，创建受归属、企业策略与平台核验状态约束；无维护权时明确提示。微信绑定二维码在本地生成，关闭后停止轮询；embed 尚未接入时明确标注计划状态。员工旧渠道和集成链接回到新对话，不加载治理界面。

MCP 注册位于管理端工具箱，MCP 服务发布位于发布集成，拥有 `tools:manage` 的用户才能配置和签发；个人专属令牌尚未完成。一次性令牌不进入列表或持久存储，切换账号、企业、离开设置和关闭弹窗时清除。已删除的 Ollama/Cloud 设置、API/CLI/Chrome/Claw 集成与本地浏览器连接入口不再提供操作。

管理端仅以当前企业服务端 `entries` 与 API 权限展示入口和操作；业务路径变化时重新校准，同页编辑查询不重置上下文，权限读取失败时禁止写入并提供重试。企业切换只接受当前账号所属企业，切换后清理原企业表单、权限与在途响应。企业策略提供变化字段提交、保存确认、只读状态和失败重试；部门列表不可读时不覆盖原范围，会话保留关闭时明确提交不自动清理。

成员管理仅向具有 `members:manage` 的用户读取和展示。活跃成员支持搜索、分页、基础角色调整及移除；人员邀请与有效链接区分显示，可创建和撤销。创建新邮箱账号时使用临时密码并要求首次改密，密码与邀请链接不持久化。涉及 owner 的操作遵守调用者 owner 和最后一名 owner 保护；对自身变更后立即校准身份与权限。无独立停用/恢复接口时，不把移除包装为停用；加入申请审批已接入成员页的独立标签。

加入申请仅向成员管理员显示待审批记录。批准须选当前企业启用部门和允许的基础角色，部门按可读路径选择，不要求手填 ID；部门不可读时禁止批准并提供说明，拒绝不依赖组织权限。拒绝原因非空且不超过 500 字符，确认前说明 7 天冷却期。批准成功后刷新成员信息；失败保留表单，切换作用域、权限变化及离开标签后旧表单与回执均失效。


部门组织管理按 `org:manage` 授权，支持组织树、手工节点维护及直接成员归属。根节点不可移动或删除，移动不可形成环路，删除由服务端检查全部关联。成员候选依赖额外的 `members:manage`，不得要求输入内部 ID；缺少候选权限仍可维护手工部门的已有成员归属。主部门以服务端回执及刷新结果为准，移除关联不等同于移出企业。界面对 `source=wecom` 节点及其成员归属只读，允许在启用节点下创建手工子部门；服务端来源保护和混合根同步标记尚未完成，不能宣称全链路只读。树和成员读取失败必须阻止依赖未知数据的写入，切换部门与作用域作废旧请求及确认。


企业管理主框架必须对齐 workspace：左侧品牌、可折叠的图标导航、固定左下角的登录用户入口，支持所属企业切换及退出。管理端与工作台为独立应用，主框架不提供返回工作台或关闭入口。业务内容继续复用公共主题、设置行和列表样式。所有现有权限、加载/失败反馈、确认及作用域隔离行为保持有效。


企业信息：管理端当前企业 owner 可以查看基本信息、修改名称与描述、按名称确认删除。企业切换及身份失效时旧表单和确认作废；加载、保存和删除错误均提供反馈。企业编码因既有详情接口缺少字段暂未接入，不以 UUID 替代。


角色与权限：具有角色管理权限的成员可以搜索和查看角色、创建自定义角色、编辑自定义角色权限；内置角色只读。权限目录来自服务端且不得超出操作者已有授权；现有契约不支持角色改名和删除。额外具有成员管理权限时，可以按名称选择成员、分配或撤销角色；owner 无需新增分配。操作前确认，失败保留可重试状态，成功刷新身份及权限；身份变化后旧请求、草稿和确认失效。


部门批量角色分配：具备角色、成员及组织管理权限时，按完整部门路径选择启用部门与自身可授予的角色，确认后只分配直接活跃成员，不含下级和未来成员。结果反馈实际新增与已分配跳过人数；组织读取失败禁止部门写入，其他管理区保持可用。服务端同时要求角色及成员管理权限，并拒绝授予超出操作者权限的角色，失败不产生部分分配。


角色到企业智能体使用授权：按角色和企业智能体名称设置查看/运行或撤销当前角色授权，事前确认且不授予维护权限。候选限于现有接口可见范围，不宣称完整目录，不把治理可见性当作使用授权。未解析的既有授权明确提示；撤销不覆盖其他授权来源。独立加载失败可重试，服务端拒绝保留草稿，身份/目标变化后旧确认与响应失效。


工作台旧部门设置：部门维护集中到独立管理应用，工作台不再提供重复部门写入口。旧书签显示迁移说明，有当前企业管理入口的用户可主动打开管理后台；无入口说明权限不足。不得自动跨应用跳转，尚未承接的退出企业和审计等流程需继续保留。


管理端审计：按 audit:read 显示最近记录和元数据详情，明确列表读取上限及本地筛选范围，提供现有 UTC 日期范围 JSONL 导出，不伪造全文查询或正文查看。错误、空结果、无匹配及无权限有明确反馈；身份变化后不得展示或下载旧企业数据。


个人企业成员身份：账户资料展示当前有效企业的真实只读信息，普通成员可确认退出本人当前企业而不删除账号或企业；owner 须先转移所有权并调整角色。操作失败可重试，身份变化后旧操作与响应失效。旧企业信息管理页面清理后，旧链接仍进入账户资料；个人资料和改密能力保持。


工作台成员治理收尾：移除重复成员/邀请/审批/审计页面和导航，旧 members 书签显示显式管理应用入口，不自动导航或触发治理请求。当前企业入口变化时链接随之更新；共享空间成员管理与个人加入/邀请等日常流程继续保留。模型、工具、存储等其他管理配置不以本批清理替代迁移验收。

### 企业智能体管理

- 后台在服务端授权下列出可见的企业智能体，提供搜索、企业归属创建、完整配置编辑并发布和归档确认；个人智能体不混入企业目录。
- 两应用共用同一完整编辑器，个人创建接口保持不变。企业只能选择企业知识库，已有不可见绑定不得因候选查询而被清空。
- 发布失败保留已保存草稿并支持重试；身份/企业/权限变化使旧表单和后续发布失效。归档保留已有会话并阻止新运行，当前没有恢复入口。
- 模型管理尚未迁移时显示说明；部门/成员受众、渠道及试运行仍待后续实现，不以当前目录宣称企业资源管理全部完成。

### 企业知识库目录、设置与内容管理员

- 企业知识库和智能体目录沿用固定版 WeKnora 的标题栏、工具栏、紧凑卡片与更多操作布局，支持按名称搜索和排序。知识库内容页提供面包屑、可管理知识库切换与内容工具栏。
- 当前有企业知识库管理权限的用户可查看本企业可见的企业库目录及类型、可见范围、文档数，不混入个人资源或外部共享库。
- 对服务端允许管理的知识库，可以查看、指定和撤销内容管理员，确认需显示具体知识库和成员，并解释授予范围与其他授权来源。
- 新增从当前企业活跃成员的姓名/邮箱选项选择，不要求输入内部 ID。没有成员名单权限或成员查询失败时禁止新增，保留已有管理员查看与撤销。
- 查询失败、空结果、写入失败和写入成功后刷新失败分别反馈；目标/企业/身份/权限变化及卸载作废旧状态和确认。窄屏应能操作完整面板。
- 企业管理员可复用完整知识库编辑器创建和编辑企业库；创建后可继续配置同一资源，读取失败可重试而不生成副本。编辑保存保留未知设置，既有存储/向量绑定只读，权限和企业归属由服务端响应校验。
- 企业知识库管理员可从目录设置部门与成员读取受众。部门和成员候选分别受 `org:manage`、`members:manage` 保护；无法读取的类别保留原绑定，收窄受众的智能体兼容性由服务端校验。
- 工作台个人创建路径保持不变，公共编辑器不依赖具体应用。后台按库类型维护文档（上传、下载、删除、处理重试）、FAQ（条目 CRUD）和 Wiki（页面 CRUD 与版本冲突反馈）；内容接口沿用现有契约并逐次受服务端维护权限校验。企业知识库目录允许管理者按名称确认删除，并明确访问终止和异步清理后果。标签/目录、分块预览、批量导入导出、Wiki 修订历史及共享治理复核仍待迁移；不宣称企业知识库治理全部完成。


管理端企业模型目录支持共享 Provider、模型版本、按类型默认值、停用和连接测试。个人模型与企业目录隔离，密钥仅写入不回显；测试调用仅适用于聊天模型并可能产生费用。工具/存储等管理配置与工作台产物隔离仍待后续验收。


管理端企业 MCP 端点支持只读工具与知识库范围配置、启停、令牌轮换/撤销和删除。令牌只在签发或轮换后短暂展示，服务端逐次校验权限和端点范围。MCP 工具风险管理与存储配置仍待后续迁移。

管理端企业 MCP 客户端目录支持服务配置、启停、连接发现、工具目录查看及逐工具启用；发现到的新工具默认关闭。管理员可设置工具风险级别与调用审批，降低已观察风险前必须确认，最终风险仍由服务端复核。MCP 注册与工具箱管理只在企业管理端提供，两应用的公共契约留在 core。

## 企微组织同步来源

组织管理页面须区分同步节点结构和成员归属来源；混合归属撤销须提示只撤销手工来源。企微设置页须如实显示排队与完成状态，有限轮询需在身份、权限变化及卸载后失效。

## 企业编码只读展示

企业信息页应显示并复制真实企业编码；缺失时明确提示，不能复制内部 ID 作为替代值。

工作台不得保留未被当前路由使用的旧模型配置、Ollama/Cloud 编辑和模型调试实现。清理时须保留聊天工具草稿和深链接：只读入支持的无凭据字段，由用户输入密钥并保存；local 草稿明确提示不支持。切换身份或卸载后，旧目录响应与连续模型写入链不得继续影响当前页面。共享选择器和资源编辑能力继续保留。

员工工作台的存储/向量库治理书签与知识库配置快捷入口应展示独立管理应用的迁移说明。普通设置导航不加载治理页面；无 Admin 入口时不显示管理链接，身份变化后即时更新。说明不自动导航或请求治理目录，知识库配置的读取、选择和已有绑定继续可用。

## 企业解析配置

当前企业 owner/admin 可在管理应用维护已有四类外部解析器参数。目录明确区分配置完整和未就绪/计划中，不把配置完整当作网络测试。密钥留空保留、显式清除或一次性轮换；保存前确认，失败保留普通草稿并清空新密钥。旧工作台 parser 书签显示迁移说明，知识库解析规则选择继续可用。

## 浏览器回归

Web 工程提供可重复运行的双应用 Playwright 命令，首批覆盖独立登录、解析配置确认保存和工作台治理书签迁移，并检查手机宽度与页面脚本错误。模拟接口必须显式声明，不连接本地数据库；模拟用例通过不代表真实 API 与完整业务验收完成。

共享登录卡片与工作台整页设置应随视口收缩，在 375px 宽度下不产生页面横向滚动。

完整验证入口须检查 core 与两个应用全部原有 TS/Vue 源文件，并产出独立的 workspace/enterprise 生产包。资源控制不能通过排除业务文件、关闭模板检查或删除预览格式获得通过；生产模块图须校验两应用边界，预览回归使用真实产物。

企业管理侧栏仅提供以下业务分组与顺序。配置（模型、知识库、工具、智能体）、空间（企业空间、企业策略）、发布集成（MCP服务、IM 集成）、数据与扩展（向量引擎、解析引擎、存储引擎、沙箱引擎、知识图谱）、权限（企业组织、用户、角色）、系统（系统设置、运行状况、审计日志）。链接按当前企业授权过滤，页面沿用本地 WeKnora 的对应组件及已接入交互。

用量限额确认须绑定原始范围和数值，重复操作不得建立并行写链；已返回报表按实际查询分组解释。成员/部门目录失败须明确反馈，不提供失败目录的新增范围，企业范围操作仍可用。相关权限变化须使旧确认及异步结果失效。


## 员工功能范围与管理配置

员工主菜单只有新对话、知识库、智能体，设置始终弹出且仅提供账户下常规设置、用户信息、我的记忆。知识库只维护已有授权内容，不能创建；智能体只查看和使用。旧工具箱、自动化、产物库、共享空间、渠道地址不加载旧界面。空间长期记忆、资源配置与工具/MCP管理归企业管理应用。当前企业身份、切换与本人退出保留在账户流程中。

产物属于当前会话，放在右侧可折叠面板；支持预览、受认证下载、错误重试及空状态。切换会话立即清理旧产物与预览，迟到响应不得覆盖新会话。企业系统设置提供主题及弹出、替换路由、抽屉三种二级编辑展示方式，界面偏好不授予企业操作权限。

企业组织使用左树、右侧操作菜单与下级组织列表。用户管理按左侧组织树筛选活跃成员，并在编辑窗口维护角色、状态和选中组织的归属。新增与编辑沿用管理端编辑展示偏好。员工设置恢复原有弹窗尺寸和内容留白，管理端系统设置参照员工布局并提供可即时切换、按用户保存的主题色。

沙箱引擎配置需提供按类型筛选和名称搜索的卡片列表，以及基本信息、连接、资源与高级参数编辑。企业 owner/admin 与平台管理员均可维护部署共享档位，普通成员和非成员不可访问。保存后衔接连接验证、供应商密钥配置与实例回收，显示不可用原因，并保护过期提交及被引用的配置。

工具管理及智能体工具配置在中文环境下须提供完整的内置工具中文名称与说明。分组总开关位于组内子工具列表上方，切换后同步所有可维护子项；子项支持单独开关及部分开启提示。部署不可用、空间停用、维护权限与基础组门控继续生效。

### Workspace 我的记忆

设置中的“我的记忆”提供“配置”和“记忆”两个顶层 Tab。配置承载个人开关、自动提炼模型、容量策略、用量与整理；记忆承载既有待审核、已发布、兴趣主题、常用资料及归档说明。用户可填写标题、类型、正文、重要度并明确发布私人记忆；归档需确认并保留历史，归档列表恢复仍为计划能力。
