# 目录用途

应用布局。

- `AppLayout.vue`：侧栏与路由页面的框架，负责断点与抽屉状态、平台管理页面的访问检查，并挂载设置弹窗。
- `AppSidebar.vue`：顶部搜索与收起按钮、主要操作（新对话、知识库与智能体为计划项、共享空间）、当前空间的会话（按最近更新分组）、管理分组与用户菜单（语言、设置、退出）。侧栏宽度可拖拽或用方向键调整并记忆。
- `SessionSearch.vue`：会话搜索面板，只过滤已加载的会话标题，支持键盘选择与回车打开。
- `SettingsDialog.vue`：设置弹窗（左侧分区、右侧内容）。阶段 1 只实现"常规设置"（语言、主题），其余分区为计划项。
