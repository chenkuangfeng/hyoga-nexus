# 目录用途

对话页与运行时间线。

- `ConversationView.vue`：标题栏（会话标题、运行状态、刷新）、时间线、输入区（智能体选择、发送与停止）；模型分支与记忆快照收在"会话工具"折叠面板中。新对话是草稿，会话在第一条消息发送时创建。
- `ChatTimeline.vue`：把运行事件渲染为有序的文字与步骤（工具、审批、追问、深度思考），并显示思考轮数、工具次数与耗时。

状态来自 `composables/useConversation.ts`；事件由运行的 SSE 流提供。深度思考需要运行时发出 `message.delta` 且 `kind: 'reasoning'`，目前运行时尚未发出，界面已预留。
