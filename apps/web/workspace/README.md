# @nexus-web/workspace

员工工作台 Vite 应用，包含主入口 `index.html` 和独立嵌入入口 `embed.html`。

`src/` 提供员工工作台页面、组件、路由和状态；公共 API、认证、语言、基础主题、智能体/知识库编辑器和渠道组件引用 `@nexus-web/core`。工作台与 `/admin/` 管理后台是两个独立应用，不提供应用间的返回菜单。

在 `apps/web/` 运行 `pnpm dev:workspace`（5173）、`pnpm --filter @nexus-web/workspace build` 或 `pnpm --filter @nexus-web/workspace test`。产物为 `workspace/dist`。开发服务保留 `/embed/:channelId` 到嵌入 HTML 的回退和 API WebSocket 代理。

平台管理页面与路由、Wails 绑定、桌面自动登录和地址恢复已移除。旧平台管理地址显示公共 404；旧设置查询归一到常规设置。注册页只提供企业注册，邀请注册加入已有企业。改密入口要求认证，临时密码账号先完成改密才能进入工作台。普通令牌恢复与部署允许的开发登录继续使用统一认证 API。

旧浮动助手的面板、设置、侧栏/命令入口和文档/Wiki 唤出动作已移除。普通聊天仍支持工具卡片与表单草稿跳转；草稿在内存中一次性消费，切换账号或企业时清空。资源变更后的列表与文档刷新仍使用公共通知契约。

智能体卡片的「渠道」进入 `/platform/agents/:agentId/channels`；IM 管理由公共组件承载，embed 后端尚未接入并在界面标为计划状态。账户设置的 MCP endpoint 使用现有企业服务端契约，`tools:manage` 控制签发与管理；个人专属令牌尚未实施。旧集成链接兼容迁移到智能体渠道或账户设置，Ollama/Cloud 设置、API/CLI/Chrome/Claw 集成和本地浏览器连接入口已删除。一次性令牌和绑定二维码只保留当前页面内存，身份切换时清空。

企业智能体共享设置支持按部门和成员分配直接使用受众。该设置授予 view/run，不替代角色授权或共享空间分享；目录不可读时保留既有受众，不会以空列表覆盖。


## 已迁移的部门管理

部门、成员治理、企业资源与运行管理位于独立企业管理应用 `/admin/`。工作台不注册这些治理页面；需要管理权限的旧书签会给出迁移提示或指向对应管理页。共享空间、加入企业、切换企业、个人设置和个人退出企业仍由工作台处理。管理业务已按 E2 逐步迁移，完整工作台类型/构建和产物隔离验收仍由 E2.8 跟踪。


## 当前企业成员身份与退出

账户资料（`section=userprofile`）包含当前企业只读信息和本人退出操作，使用有效企业 ID，不误用账号默认企业。普通成员无需管理权限或成员名单读取即可确认退出；任何 owner 均须先转移所有权并调整角色，页面与现有后端规则一致。退出前显示企业名称和资源访问影响，失败保留错误和确认、提交中禁止重复操作，成功清除本地身份并在工作台登录页重新登录。企业/账号/角色变化使旧确认和迟到结果失效，企业资料变动通知会刷新只读信息。

旧企业信息页的治理编辑/删除已由独立管理端承接，工作台旧 `tenant` 设置书签与 `/platform/tenant` 路径进入账户资料页，个人资料与改密保持原流程。实现为 `CurrentEnterpriseMembership.vue`，沿用现有 GET `/tenants/current` 与 POST `/tenants/{id}/leave`，没有改变后端权限规则。


## 已迁移的成员管理

工作台旧成员治理页和其独占审批组件已删除，不再提供成员管理导航。成员、邀请、加入申请审批和审计分别由独立管理端 `/admin/members`、`/admin/audit` 承接。旧 `section=members` 和内部旧快捷调用只显示迁移说明，提供显式链接，不自动跳转，也不读取成员/邀请/申请/审计接口；入口按当前企业服务端 entries.admin 显示，管理端继续校准每项权限。

共享空间成员管理、个人邀请通知、加入企业、当前企业成员身份和退出企业保持原流程。管理端模型、工具、MCP 与存储/检索等页面已有独立实现；生产工作台产物是否完全隔离管理代码仍待 E2.8 验收。

## 模型配置与旧入口清理

设置使用 `NexusModelSettings.vue` 和 `NexusModelEditorDialog.vue`，通过 Nexus Provider/模型档案接口维护个人模型。聊天工具的模型草稿在当前目录加载后一次消费；只预填名称、提供方名称、URL 和支持的类型，凭据由本人输入，local 草稿明确提示不支持。`model_id` 深链接只打开可管理档案。

孤立的旧 ModelSettings、ModelEditorDialog、ModelDebugDrawer 及其独占目录缓存、Ollama/Cloud 和桌面浏览器配对辅助已删除。共享模型选择器、资源编辑器和通用模型引用工具继续保留。身份切换和卸载使目录读取、测试及连续保存结果失效；已创建供应商而模型保存失败时，重试复用该供应商。

## 企业存储与向量库配置

企业文件存储和向量库治理已由 Admin 的 `/storage`、`/vector-stores` 承接，员工设置导航不再加载旧治理页面。`?section=storage`、`?section=vectorstore` 旧书签及知识库“管理配置”快捷调用显示迁移说明；只有当前身份具备 Admin 入口时显示显式链接，不自动跳转或请求治理目录。无管理入口时提示联系管理员。

知识库编辑器继续读取并选择已有存储/向量库，保留原绑定。core 的目录适配器、共享文案和 providerLogo 仍有消费者；其他未完成迁移的设置保留后续任务。存储编辑、默认后端及未保存配置测试仍等待服务端实现，不能由旧页面的占位按钮推导为可用。

## 企业解析引擎配置

企业解析参数由 Admin `/parsers` 承接；旧 `?section=parser` 书签显示迁移说明，有 Admin 入口的身份可显式打开独立管理应用。旧 ParserEngineSettings 已删除，知识库中的解析规则选择继续保留。检测、DocReader 重连及 WeKnora Cloud 凭据状态没有现行接口，不提供操作。
