# 聊天操作栏与输入栏

### MODIFIED Requirements

#### Requirement: 新会话欢迎区域
欢迎区域 MUST 显示标题“Hi，我是Nexus”，并 MUST NOT 显示推荐问题占位区。

#### Requirement: 消息操作
消息下方每个可见操作 MUST 完成其操作或提供清晰的失败状态；不得将“暂未开放”作为操作的实现。分叉 MUST 保留原会话并复制所选消息之前的授权历史；回滚 MUST 拒绝活动 Run 并保持消息与工作区状态一致。复制、知识保存、产物打开和请求详情 MUST 使用当前会话及消息的授权数据。

#### Requirement: 输入栏运行选项
联网搜索、图片/附件、知识提及、模型选择和推理强度 MUST 通过 Run 请求显式传递；服务端 MUST 验证资源、模型和工具的当前权限，并将选项纳入幂等判断与 Run 快照。未提交选项的旧客户端请求 MUST 保持当前默认行为。
