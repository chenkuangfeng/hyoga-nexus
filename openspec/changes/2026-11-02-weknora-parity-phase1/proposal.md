# WeKnora 对齐 第 1 阶段：外壳与对话

## 状态

草稿，待确认。父提案：`openspec/changes/2026-11-02-weknora-parity/`（已确认）。在本提案确认前不编码。

## 背景

父提案要求界面按 WeKnora 复刻，并保留 Element Plus。当前外壳已由 `2026-11-02-web-shell-layout` 完成（侧栏、vue-router、四组导航），但与 WeKnora 相比仍有差距：

- 侧栏：WeKnora 的顶部是 Logo、搜索、收起三个按钮；导航为「新对话、知识库、智能体、共享空间」；会话按「今天 / 近30天」分组，并可搜索。本仓库的侧栏是空间选择器加四组导航，会话列表只在"工作台"下显示。
- 对话页：WeKnora 的回答是时间线（思考、检索、读文件、写文件等步骤），顶部显示「思考 N 轮 · 调用 N 次工具 · 耗时」，输入框底部有模式与模型选择。本仓库的对话页有标题与介绍段落，工具进度只是文字列表。
- 语言：父提案要求中英文一次完成。当前全部文案是硬编码中文。

截图依据：WeKnora 仓库 `docs/images/qa.png`、`docs/images/agent-qa.png`、`docs/images/settings.png`。这些截图可能早于当前代码（导航条目不完全一致），以代码为准，截图只用于外观比对。

## 范围

### 范围内（前端，不改 API 契约）

1. **i18n 框架**：引入 `vue-i18n`，建立 `zh-CN` 与 `en-US` 两份文案，并接入 Element Plus 的 locale。语言切换放在侧栏底部用户区。
2. **侧栏重做**（对照 WeKnora `menu.vue` 的布局）：
   - 顶部：Logo、搜索按钮（打开搜索面板，见下）、收起按钮。
   - 导航：新对话（点击开始新会话，下方列出最近会话）、知识库（占位，第 3 阶段实现，显示为"计划中"）、智能体、共享空间。
   - 会话按「今天 / 近30天 / 更早」分组，当前会话高亮。
   - 侧栏可拖拽调宽（最小与最大宽度有限制，宽度存入 localStorage）。
   - 搜索面板：仅在前端搜索已加载的会话标题（不新增后端搜索接口）。
3. **对话页**：
   - 去掉页面标题与介绍段落，顶部只保留会话标题与操作按钮。
   - 用户消息右对齐，气泡样式；助手消息左对齐。
   - 时间线：把 `timeline` 中的事件渲染为步骤（推理、工具调用、检索、审批、追问），每步有图标与状态；顶部汇总"思考轮数、工具调用数、耗时"。
   - 工具结果：可展开的结果卡片（默认折叠，展示输入与输出摘要）。
   - 审批卡与追问卡：沿用现有 `pendingInput` 数据，改为 WeKnora 风格的卡片，行为不变。
   - 深度思考：有 reasoning 内容时显示折叠块。
   - 输入区：底部工具栏（模式下拉、附件占位、@ 占位、模型显示），发送按钮与 WeKnora 位置一致。
4. **设置弹窗的外壳**：本阶段只做"设置"入口与弹窗框架（左侧分区、右侧内容），分区内容在第 2 阶段填充。"常规设置"中的语言与主题切换在本阶段接入（主题只做浅色，见范围外）。

### 范围外（另行提案）

- 会话置顶、重命名、清空、批量管理：需要后端新增字段与接口（`sessions` 表增加 pinned、title 更新、批量删除等），属于 API 与持久化变化，单独提案：`2026-11-02-session-management`。
- 子智能体与后台任务的展示：取决于运行数据是否已包含子运行信息；先在提案中核对 `runs` 与 `timeline` 的数据，若不足则单独提案。
- 全局搜索（后端检索）、深色主题、Ollama 等排除项。
- 知识库页面的实际内容（第 3 阶段）。

## 需要你决定的项

1. **i18n 覆盖范围**：本阶段把所有现有页面的文案都迁到 i18n（与"一次加好"一致，工作量较大），还是只迁移外壳与对话页，其余页面在各自阶段迁移。建议：全部迁移，避免中英文混杂的中间状态。
2. **会话分组的时间依据**：按会话的最后更新时间分组（需要后端返回 `updated_at`，现有接口应已提供，需核对）。建议：按 `updated_at`，若接口缺字段则在本阶段只做"全部会话"单组，不新增字段。
3. **对话页标题**：去掉"对话工作台"标题与介绍段落（与 WeKnora 一致）。建议：去掉。

## 验收

- 中文与英文切换后，外壳与对话页无硬编码中文文案。
- 侧栏结构与 WeKnora 截图的层级一致：顶部三个按钮、四个导航项、按时间分组的会话列表、底部用户区。
- 对话时间线能渲染现有的所有事件类型；审批与追问的提交行为与现在一致。
- Element Plus 组件保留；不引入 TDesign。
- 浏览器测试覆盖：侧栏导航、会话切换、语言切换、时间线渲染、审批卡提交。
- 375 / 768 / 1024 / 1440 px 下无横向溢出（沿用现有验收）。
- 不改变任何 API、权限判断或数据模型。
