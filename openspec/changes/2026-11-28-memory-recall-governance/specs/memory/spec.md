# 记忆召回与事实治理

### 新增：按需记忆上下文

- Agent 可分别控制 Profile 常驻注入和逐轮自动召回；两者默认关闭。
- 关闭自动召回时，Run 不得按用户输入自动搜索并注入记忆；已授权的 `search_memory` 与 `read_memory` 仍可由模型主动调用。
- 关闭 Profile 注入时，Profile 正文不得因旧会话快照进入模型请求；相关条目仍可通过记忆工具读取。
- 记忆目录保持有界，只显示查找所需的标题和标识，不在每次请求中装入所有记忆正文。

### 新增：事实身份安全

- 新提议可记录主体、属性、范围、更新意图及证据。
- 同主题或语义相似仅用于发现候选；除非有唯一事实键匹配或显式目标和版本，否则不得静默把新提议转成旧条目编辑。
- 模糊候选以重复/冲突提示展示，已发布记忆只能通过所有者审核发布变更。

### 新增：记忆来源轨迹

- 轨迹区分 Profile 注入、自动召回、模型主动搜索和主动读取。
- 上下文注入来源不计为模型请求或工具调用；每项展示条目、版本和来源消息（可用时）。

### 新增：检索质量评估

- 评估覆盖同义召回、同主题不同事实、明确纠正、时效范围、删除抑制和按需读取。
- 关键词与向量任一通道不可用时，搜索仍可降级运行；评估报告区分召回命中和事实身份误合并。
