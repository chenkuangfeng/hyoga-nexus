# 会话轨迹与产物标签

## 动机

工作台会话页的产物目前占据右侧面板，用户需要切换到轨迹时也缺少直观入口；Run 事件虽记录模型调用，但没有每次请求的上下文估算，难以区分单次消耗与累计消耗。

## 范围

- 将非嵌入会话页组织为顶部“对话、轨迹、产物”标签。
- 移除会话右侧产物栏，把会话产物放到独立标签。
- 基于持久化 Run 事件投影时间顺序轨迹，展示模型调用、工具调用、上下文压缩和运行状态。
- 为每次模型调用记录请求上下文 token 估算、供应商实际用量（若提供）及 Run 累计 token，并在轨迹中标明其口径。
- 保留原始消息、Run 与事件审计结构；不新增持久化表。

## 非目标

- 不复刻 DeepSeek Harness 的虚拟化检查器和完整时间轴交互。
- 不展示完整模型提示词或工具定义，不改变发送给模型的消息。
- 嵌入式聊天继续保持紧凑对话布局。

## 验收

- 桌面和窄屏会话页均可用键盘访问三个标签；嵌入式聊天不受影响。
- 产物只在“产物”页集中展示，原右侧产物栏已移除。
- 轨迹按 Run 与事件顺序展示模型请求、工具过程、压缩与状态事件。
- 模型请求行显示上下文估算；完成行展示供应商用量（若存在）及 Run 累计 token，不把累计值误报为单次请求用量。
