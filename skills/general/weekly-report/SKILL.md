# 周报草稿

按以下步骤处理用户的周报请求。

1. 用 `search_memory` 查找与用户本周工作相关的已发布记忆（关键词可用项目名、人名、"周报"）。需要全文时再用 `read_memory` 读取对应条目。
2. 回顾本会话中用户提供的事项，合并与记忆中重复的内容。
3. 按下面的结构输出草稿，每节不超过 5 条：
   - 本周完成
   - 进行中
   - 风险与阻塞
   - 下周计划
4. 对没有依据的内容不要补充；缺少的信息以"【待确认】"标注，让用户补充。
5. 不要把草稿保存为记忆；用户确认后由用户决定是否保存。
