# Web 需求

Web 提供 Native 对话工作台、平台能力状态和用户设置。

模型设置支持个人/空间共享范围、多个供应商与多个模型、按类型筛选与搜索、凭据替换、连接测试、按作用域与类型的默认模型。已有会话保持固定模型版本。

智能体页面支持创建、编辑、复制、删除（归档）智能体并从卡片开始对话；编辑器提供基本信息、系统提示词、模型与生成参数（温度、最大生成 Token、思考强度、最大迭代次数、模型调用超时）和工具选择。保存即发布新版本，已有会话不受影响。

Key 只用于一次性输入，不写浏览器持久存储、不回显；取消、提交结束或离开页面时清除输入。页面提供空态、加载、错误、操作反馈和停用确认，在桌面/窄屏与键盘下可使用。

Native 与记忆设置页提供个人预算、重试、回合恢复、项目上下文、故障转移模型和已登记工具选择；保存后仅影响新建智能体。记忆支持审核发布、读取历史版本、恢复与归档。会话支持候选回答、运行中追加指令、逐调用审批及保留历史创建模型分支。

## 企业化工程边界

Web 分为公共源码包 `core`、员工工作台 `workspace` 与企业管理后台 `admin`。公共包不得依赖应用，两个应用互不依赖；接口契约、认证、企业切换和基础偏好共用。管理入口以当前企业服务端返回的 `entries` 为准，缺失时不根据角色推断入口。业务重构与验收范围见企业化提案 E2，当前独立管理入口仍为骨架。
