## ADDED Requirements

### Requirement: 企业共享模型管理
管理应用 SHALL 按 `models:manage` 提供当前企业共享 Provider、模型配置、模型版本和企业默认模型管理。页面和客户端 SHALL 仅展示 tenant scope 的 Provider，不得读取或修改成员个人模型；所有请求 SHALL 使用当前企业路径，身份、企业或权限变化后 SHALL 丢弃迟到的响应。

#### Scenario: 管理入口权限
- **WHEN** 用户没有当前企业 `models:manage` 权限
- **THEN** 模型导航和智能体编辑器中的模型管理跳转均不可用，并显示权限提示

#### Scenario: 保存共享 Provider
- **WHEN** 管理员创建或更新企业 Provider
- **THEN** API Key 仅在提交时写入，页面不回显密钥；修改 API 地址时要求重新提交密钥，个人 Provider 不出现在目录中

#### Scenario: 追加模型版本及默认值
- **WHEN** 管理员编辑已有模型或设置某类型默认模型
- **THEN** 编辑追加不可变版本且模型类型不可变；默认值只能指向当前企业同类型模型的当前版本，服务端拒绝无效引用

#### Scenario: 停用和连接测试
- **WHEN** 管理员停用模型或执行连接测试
- **THEN** 停用保留历史版本并清理相关默认值；测试对对话、向量化与重排模型发送最小请求并明确可能产生费用；视觉和语音返回不支持，错误信息不泄露密钥

#### Scenario: 浏览和添加企业模型
- **WHEN** 管理员打开企业模型目录
- **THEN** 默认展示全部模型及各类型数量，支持按类型、模型名称或服务商名称筛选。点击模型卡片可编辑，添加模型表单预填当前筛选类型，允许选择已有服务商、常用模板或自定义接入

#### Scenario: 在同一表单添加模型与服务商
- **WHEN** 管理员从添加模型表单选择常用模板或自定义接入
- **THEN** 同一表单允许填写模型和接入配置，模板预填名称和地址。切换服务商时清空临时密钥。草稿连接测试可使用当前输入，保存时新服务商、凭据和模型在同一事务提交，任何一步失败时一并回滚。

#### Scenario: 复制企业模型配置
- **WHEN** 企业管理员从模型卡片复制当前配置
- **THEN** 副本保留服务商、上游模型 ID、类型及选项，拥有独立档案和起始版本，展示名追加后缀并解决同服务商内的同名冲突。凭据引用复用，默认值与资源绑定保持原归属。

#### Scenario: 测试未保存的模型
- **WHEN** 企业管理员从模型表单测试选中服务商的当前草稿
- **THEN** 服务端使用该服务商凭据测试草稿中的模型 ID、类型及协议，仅返回经清理的状态与提示。更改测试参数、关闭编辑器或切换企业时清除测试结果。

### Requirement: 操作弹层布局
企业模型和服务商操作弹层 SHALL 使用独立于触发按钮的内容宽度，并保持操作标签可读。

#### Scenario: 在窄屏打开模型卡片操作
- **WHEN** 管理员展开模型操作弹层
- **THEN** 常规操作标签保持单行，弹层留在视口内，支持键盘连续聚焦和 Escape 返回触发按钮
