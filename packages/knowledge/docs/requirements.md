# 知识库需求

完整保留 WeKnora 知识库功能，分阶段实现（K0–K7，见 `openspec/changes/2026-11-06-knowledge-base`）；已实现部分如下，其余在能力目录中标「待实现」。

## 已实现（K0、K1）

- 文档库：创建、配置（索引策略、分块、Embedding 模型、向量库、存储后端）、共享、删除、重建。
- 文档：上传去重、不可变版本、新版本索引完成后才切换、解析失败原因与重试、块预览、下载、删除。
- 向量库：可注册多个，每库选一个；SQLite 内置，PostgreSQL（pgvector）、Qdrant、Elasticsearch、Milvus 已实现待真实环境验证。
- 检索：先确定调用者此刻可读的库与文档版本，再在范围内做关键词与向量检索并融合；向量不可用时退化为关键词并说明原因。
- 智能体：绑定多个库，获得 `search_knowledge`、`read_document`、`list_documents`；`[ID:n]` 证据登记；Run 结束解析引用，无效引用只记事件。
- 管理：检索测试、活动日志、向量库与存储后端管理页。

## 约束

- 无权内容不得经任何通道（关键词、向量、降级）返回；撤权、删除、版本切换在下一次检索立即生效。
- 无效引用不使 Run 失败，评估时计为失败。
- 解析首期仅文本类与文本型 PDF；扫描 PDF、Office 文档等见 K4。
