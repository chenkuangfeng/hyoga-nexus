# 工具箱：把 WeKnora 的「工具箱」页接到 Nexus 后端

## 状态

已确认（2026-11-08）：决定 1 计划中、2 成页面（与推荐不同）、3–6 按推荐。下文保留各项说明。

## 原因

顶级导航里已有「工具箱」入口，路由 `/platform/toolbox/:section?` 现在渲染 `PlannedPage`（占位说明），因为复制来的 `views/toolbox/Toolbox.vue` 调用的是 WeKnora 的后端（`/api/v1/skills`、`/api/v1/mcp-services`、本地浏览器连接），Nexus 没有这些接口。技能演进提案（`2026-11-07-skill-evolution`）已经把技能的后端做全了，但管理入口散在智能体编辑器的几个对话框里；内置工具的启用与停用也只能在编辑器里做。工具箱应成为这些「空间级资源」的统一管理页。

## 现状（读码所得）

| 部分 | 现状 |
| --- | --- |
| 路由与导航 | `router/index.ts` 的 `toolbox/:section?` 指向 `PlannedPage`；`config/toolbox.ts` 定义标签（技能、MCP、浏览器连接）与角色/部署能力门禁；`Toolbox.vue` 是 WeKnora 页面，内嵌 `SkillSettings`、`McpSettings`、`BrowserConnectionSettings` |
| 技能后端（Nexus） | 列表（含使用记录、脚本能否在所选档位运行）、版本、重扫、上传、远程安装、导出、停用/恢复内置、提交与审核、我的技能；前端已有安装、我的技能、审核三个对话框 |
| 工具后端（Nexus） | `GET /agent-tools`（内置工具目录、分组、风险、本空间是否可分配）、`tools/{name}/enable`、内置资源停用/恢复 |
| MCP | 后端未实现（路线图第 7 步「技能与 MCP」中 MCP 部分未开始） |
| 浏览器连接 | 后端未实现，也不在当前路线图内 |

## 范围

本期只做 Nexus 后端已经支持的两个标签，其余标签显示为「计划中」：

1. **技能**标签：空间技能库的统一管理页。
2. **工具**标签：内置工具目录与空间级启用/停用（只读 + 管理员开关，不改工具参数）。
3. **MCP**、**浏览器连接**：标签保留但禁用并标「计划中」，不发任何请求（与智能体编辑器里未交付的工具分组同一做法）。

不做：MCP 服务管理、本地浏览器连接、技能包、凭据；不新增后端接口（见下）。

## 待确认的决定

1. **标签范围**：技能 + 工具两个可用标签，MCP 与浏览器连接显示为禁用的「计划中」。备选：隐藏这两个标签。**推荐：显示为计划中**，用户能看到后续会有，也与 WeKnora 页面结构一致。
2. **技能标签的内容**（已确认：成页面）：技能标签下分四个子页——技能库（一张表列出空间技能库与内置技能：名称、简介、版本、来源/信任、扫描结论、使用次数与最近使用、脚本能否在所选档位运行、停用状态；行内可查看版本历史、导出 zip、重扫、停用/恢复内置）、我的技能、审核提交（管理员）、安装技能（管理员）。后三个把原来的对话框内容抽成面板，对话框与页面共用同一份实现，编辑器里的对话框入口保留。
3. **工具标签的内容**：按分组列出内置工具，显示风险级别、是否需要审批、本空间是否可分配；管理员（`tools:manage`）可停用/恢复。**推荐：只做这些**；工具参数配置与 MCP 绑定随后续提案。
4. **谁能看到**：所有活跃成员可看列表；写操作按现有接口权限（`tools:manage`、`skills:submit`），页面只负责隐藏无权限的按钮，服务端照旧复核。沿用 `config/toolbox.ts` 的角色与部署能力门禁。**推荐：沿用**。
5. **编辑器里的入口**：保留智能体编辑器技能分区里的对话框入口（编辑时顺手装技能），工具箱页是同一批对话框的统一入口，不删除编辑器入口。**推荐：保留**。
6. **后端**：不新增接口。技能列表需要的版本/信任/扫描字段，现有 `GET /skills` 与 `/versions` 已返回；若实现中发现缺字段，在本变更的 `tasks.md` 里追加，不另开提案。

## 影响

- 前端：新增 `NexusToolbox.vue`（取代路由里的 `PlannedPage`）、`NexusToolboxSkills.vue`、`NexusToolboxTools.vue`；`config/toolbox.ts` 增加「可用/计划中」标记；六种语言文案；单元测试。
- 后端：无。
- 文档：`docs/roadmap.md` 第 5 步相关条目、`apps/web` 说明。
