状态：P0 项目基线与目录骨架已落地；P1 及后续阶段待逐阶段实施。P0 本次完成静态代码/文档核对，未执行安装、服务启动或浏览器运行验证；不把目录或文档视为业务功能完成。

| P2 自研智能体闭环 | Python Native 循环，模型适配，流式事件，工具注册与调用，超时/取消，最小沙箱与文件产物 | Web 选择自研智能体→调用授权 Python 工具→返回结果→追问/取消；失败明确结束，多个会话隔离 | P1 |

## 首个产品验收点

P2 是自研智能体可用版；P3/P4 是有知识和技能的通用智能体版；P5 是多类型智能体版；P7 是观澜研究版。按验收点推进，不同时开发全部 SDK 和全部渠道。

## 下一轮建议范围

先定稿 P1 的逻辑数据模型、权限与 Runtime 目标契约，然后实现最小持久化和智能体配置。新参考项目可以调整 Native 引擎内部选型，保持平台资源和会话模型稳定。

## 测试与评估

每阶段执行涉及的单元/集成测试与前端构建。涉及鉴权、取消、重复投递、资源删除或恢复时增加对应集成场景。质量评估包括固定 Agent 任务、检索与引用、技能工具选择、不同 Runtime 的能力契约；策略回测与软件回归分开。

## 待定事项

- Native 是自主实现还是抽取 GenericAgent 部分机制：先做小型验证，不把未经隔离的原代码直接嵌入服务。
- 首批模型、账号与部署资源；外部 Runtime 支持版本和认证方式。
- 队列/调度实现、解析/OCR 与重排后端，经过验证后记录 ADR。
- 微信/QQ/企业微信各自接入模式与账号条件。
- 首批股票市场、数据源权限、频率、历史回测范围。

这些未定项不阻止当前目录与公共模型整理，也不视为已获得外部账户或服务。
