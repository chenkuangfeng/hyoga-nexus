# 规格增量：模型管理（R5 设置页）

本增量在归档时合并到 `openspec/specs/model-management/spec.md`，只替换 R5，其余需求不变。

### R5 设置页（替换）
- 页面布局与 WeKnora「模型管理」一致：顶部类型标签页显示"全部"及各类型数量，可按模型或服务商名称搜索；卡片只显示当前类型的模型，末尾为添加卡片。
- 添加打开居中抽屉，类型默认为当前标签（"全部"时为对话）。服务商下拉列出调用者可管理的服务商，末尾为"自定义（OpenAI 兼容接口）"；选择自定义后在抽屉内填写名称、地址、Key 与可见范围，保存时先建服务商再建模型。模型保存失败时，服务商已建立的情况下重试不会重复创建。
- 编辑模型时类型不可改；可修改服务商名称、地址与 Key（留空保持原 Key，更换地址时必须填写），同一服务商下有多个模型时提示受影响的数量；测试连接复用已保存的 Key（前提是不替换地址）。
- 非对话类型隐藏协议与测试连接，只发送默认协议。
- 默认模型在卡片菜单中按作用域设置或取消；空间默认只对空间共享模型、且调用者可管理空间时提供；卡片显示默认标签。
- 智能体的模型下拉只列出对话模型。
- API Key 只在提交时发送，提交后清空，不回显、不写入浏览器存储。
