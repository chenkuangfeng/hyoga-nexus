# 平台需求

平台管理身份、空间、模型、智能体固定版本、会话、运行、资源授权和审计。

模型设置支持多个个人供应商与空间共享供应商，每个供应商配置多个模型。个人配置仅本人可见和使用，空间配置由管理员维护。支持添加、编辑、停用、连接测试与个人/空间默认模型。

凭据一次性录入，服务端加密保存，不回显明文；继续支持既有环境凭据引用。缺少部署加密密钥时拒绝写入或解析密文。

明确选择优先于个人默认，个人默认优先于空间默认；默认用于新建智能体，不改变已发布智能体、会话或运行。编辑模型生成版本，相关默认指向新版本；已有智能体继续固定旧版本。停用模型或供应商清除相关默认并阻止新调用，历史数据保留。

成员可创建自己的智能体，更新/发布他人的智能体仍要求空间管理员权限。个人模型不可经共享智能体授权给其他成员。


Run 的授权、状态、消息、事件、审计及投递必须在同一业务事务内保持一致；任一后续写入失败时全部回滚，原幂等键可重试。任务领取失败不能遗留租约或消耗 attempts。共享契约和实体按职责组织时保留原导入路径及数据库约束，事件游标重放不能触发模型或工具执行。

提交、取消和输入回答的应用规则使用独立数据对象与事务端口。旧调用入口继续返回所属借用会话中的映射实体，不能为转换结果追加提交后的查询。重复请求仍检查当前权限；修改 Run 只允许当前主体在当前空间的所有者查询，不能沿用读取可见性放宽写权限。已消费输入的相同 key 和回答可重放，实际 key 字符必须保留。

## 部署数据库配置

API、worker 和迁移共享部署工作目录的 `configs/nexus.toml` 数据库 URL，支持显式注入和旧环境变量兼容；非法配置明确报错且不泄露凭据。
