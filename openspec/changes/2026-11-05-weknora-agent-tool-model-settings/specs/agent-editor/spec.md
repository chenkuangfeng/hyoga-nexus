# 规格：智能体编辑器（工具目录、生成参数、归档与复制）

来源：`openspec/changes/2026-11-05-weknora-agent-tool-model-settings`。本规格描述当前实现的行为，修改需先提案。

## 需求

### R1 工具目录
- `GET /api/v1/tenants/{tenant_id}/agent-tools` 返回已注册的内置工具：名称、说明、分组（`base`、`memory`、`skills`）、风险等级、只读、需审批、有副作用，以及 `enabled_in_tenant`。
- 同时返回分组顺序、调用者 Native 个人默认的 `enabled_tools`，以及调用者是否可启用工具（owner 或 admin）。
- 成员可读；非成员返回 404。目录不授予任何权限：绑定、发布时的资源授权与每次调用的网关复核仍然适用。

### R2 智能体级生成参数
- 草稿 `budgets.generation` 只接受 `temperature`（0–2 的数字）与 `reasoning_effort`（`off`、`auto`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`）；其他键、非数字或越界值返回 422。
- 参数随发布版本冻结；修改草稿不影响已发布版本与已有会话。
- Native 运行的模型选项 = 模型档案选项被智能体值覆盖：`auto` 沿用模型档案，`off` 不发送思考参数。故障转移模型同样适用；上下文压缩的摘要模型不适用。

### R3 归档（删除）
- `DELETE /api/v1/tenants/{tenant_id}/agents/{agent_id}` 需要 `agents:write` 与该智能体的 `manage` 权限，成功返回 204 并写审计 `agent.archived`；无查看权限返回 404，其余权限不足返回 403。
- 已归档智能体不出现在空间列表、共享智能体列表与详情中，读取、修改、发布、再次归档返回 404。
- 新建会话与提交 Run 返回 409；已排队的 Run 在准备阶段以 `agent_archived` 失败；已有会话的消息仍可读取。

### R4 复制
- `POST /api/v1/tenants/{tenant_id}/agents/{agent_id}/copy` 需要该智能体的 `edit` 权限与 `agents:write`，返回 201 与新的草稿智能体（可选 `name`，默认在原名后加 `(copy)`）。
- 复制草稿的提示词、模型、预算（含生成参数）与绑定，不复制发布版本、共享与授权；模型与绑定按调用者重新授权。

### R5 界面
- `/platform/agents` 显示当前空间可见的智能体卡片（名称、描述、工具数、版本或"未发布"），支持搜索、新建、编辑、复制、删除与开始对话；开始对话跳转 `/platform/creatChat?agent=<已发布版本 ID>` 并预选该智能体。
- 编辑器分区为基本信息、提示词、模型配置、工具配置，布局与 WeKnora 智能体编辑器一致；名称、系统提示词与对话模型必填。
- 模型配置：对话模型（只列有权使用的对话模型）、温度、最大生成 Token（默认或自定义）、思考强度、最大迭代次数（1–1000）、模型调用超时（留空为默认）。
- 工具配置：按分组显示目录，标记可写、需审批、只读；空间未启用的工具对管理员提供启用操作，对成员不可选。保存时只替换工具绑定，保留其他绑定（如技能）。
- "保存"= 保存草稿并立即发布新版本；发布失败时保留草稿并显示原因。

## 不在本规格内
- 快速问答（RAG）模式、知识库与检索、联网搜索、MCP、技能绑定界面、多模态、问题推荐、共享与发布渠道。
- 外部 Runtime 的智能体配置。
