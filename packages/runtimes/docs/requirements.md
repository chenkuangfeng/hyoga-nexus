# Runtime 需求

Native Runtime 执行模型/工具循环，保留流式事件、工具顺序、预算、取消、等待输入、检查点与生命周期 hooks。厂商类型不泄漏到公共契约。

OpenAI-compatible 模型支持来自用户设置的多个供应商。对测试连接与正式调用统一限制目的地址；流式模型测试不代表所有供应商工具协议均兼容。外部 Runtime 与隔离 Sandbox 尚未接入。

模型请求失败、缺少协议终态或工具不完整时必须显式失败；过滤/截断不得触发工具。永久拒绝不重试，暂时故障只能在输出前按版本快照内的重试预算恢复。用户取消或模型请求截止时间同时约束退避等待，事件重放不得重发请求。

用量按协议区分普通输入与缓存：Responses/Chat 缓存是输入子集，Anthropic 缓存读写是额外输入；累计 usage 快照不重复计费。真实供应商、上游 Go 和 PostgreSQL 验收各自记录，不由模拟协议测试替代。
