# 会话轨迹与产物标签

## 动机

工作台会话页的产物目前占据右侧面板，用户需要切换到轨迹时也缺少直观入口；Run 事件虽记录模型调用，但没有每次请求的上下文估算，难以区分单次消耗与累计消耗。

## 范围

- 将非嵌入会话页组织为顶部“对话、轨迹、产物”标签。
- 移除会话右侧产物栏，把会话产物放到独立标签。
- 将标题和标题后操作移出会话顶栏，三个标签紧贴顶部并靠左；标签名称为“对话、轨迹、产物”。
- 轨迹用按请求序号排列的记录表呈现，点击行在详情检查器中查看真实模型输入、响应、工具调用、耗时与 Token 用量，交互参考 DeepSeek Harness `ui-trajectory`。
- 新增独立的模型请求轨迹记录表，记录每次真实模型尝试的输入快照、工具目录快照、响应、供应商 usage、输入估算和 Run 累计量；轨迹页面从该表读取，不把 Run 事件流当作轨迹数据源。
- 保留原始消息、Run 和事件审计结构；新记录仅服务轨迹检查，不代替事件日志。
- 参考 DeepSeek Harness 按轮次分别呈现用户、助手、工具调用及结果活动；按工具调用 ID 配对结果。
- 顶部用统计方块显示请求次数、会话累计 Token 和缓存读取 Token；助手活动行在数据可用时显示实际 Token 或明确标注的输入估算。

## 非目标

- 不复刻 DeepSeek Harness 的虚拟化、时间轴缩放和完整检查器插件框架。
- 不改变发送给模型的消息、工具目录或 Run 执行语义。
- 嵌入式聊天继续保持紧凑对话布局。

## 验收

- 桌面和窄屏会话页均可用键盘访问三个标签；嵌入式聊天不受影响。
- 产物只在“产物”页集中展示，原右侧产物栏已移除。
- 轨迹行按真实模型请求记录排序；点击行可检查该次请求快照和响应详情。
- 每次成功或失败的模型尝试都有持久记录；可用时显示供应商单次用量、输入估算、耗时和 Run 累计 token，缺失用量不伪造。
- 对话顶栏不显示标题及其后的操作；标签靠左排列，产物标签名称为“产物”。
