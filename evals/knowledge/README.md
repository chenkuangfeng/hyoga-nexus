# 知识库评估

固定语料（`corpus.py`）与问答对，度量三项指标：

| 指标 | 含义 | 要求 |
| --- | --- | --- |
| 召回命中率 | 期望文件出现在前 3 条结果中的问题占比 | 关键词通道 ≥ 0.85 |
| 引用有效率 | 模型回答中的 `[ID:n]` 能解析为已登记证据的比例 | 1.0（无效引用计为失败） |
| 越权泄漏数 | 空间 A 的检索中出现空间 B 内容的次数 | 必须为 0 |

`tests/test_knowledge_eval.py` 在 SQLite 上运行关键词通道，作为回归门禁。向量与混合通道的指标需要真实 Embedding 模型，
在取得环境后用同一语料补充；PostgreSQL、Qdrant、Elasticsearch、Milvus 的真实验收复用同一语料与越权探针。
