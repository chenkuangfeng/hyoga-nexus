# 共享契约需求

为跨包通信提供稳定类型，不承担授权、数据库事务、模型 SDK 调用或执行编排。调用方负责实现协议、验证当前权限并处理异常；类型本身不能授予权限。

保留原类名、构造参数和顶层导入路径。消息区分普通内容与关联的工具调用/结果；模型流表达文本、工具调用、用量与完成。工具结果区分继续、输入等待和执行结束。执行进度和预算可持久化，取消通过能力协议传递。Run 累计 Token 用量始终统计；预算值 `max_tokens=0` 表示不启用累计硬上限，正值表示显式上限，单次输出和其他运行限制独立生效。

Native 配置负责合法值与默认值，hook 数据承载受控的上下文；具体插件注册、执行和清理留在 Runtime。
