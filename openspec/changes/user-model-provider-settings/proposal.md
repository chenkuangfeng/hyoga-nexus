# 用户模型供应商设置

## 目标与范围
在用户设置中管理多个供应商、多个模型、API Key 和默认模型，替代仅能由管理员通过 API 配置、通过环境变量提供 Key 的使用流程。

- 个人配置仅本人可使用；空间共享配置由空间管理员维护。
- 供应商支持名称、OpenAI-compatible API 地址、凭据替换与多个模型；不声称支持其他原生协议。
- Key 一次性输入、服务端加密保存，仅返回已配置状态与固定掩码。
- 支持新增、编辑、删除、测试连接，以及个人默认/空间默认模型。
- 默认优先级：显式选择 > 个人默认 > 空间默认；只用于新建智能体时预选，不修改已发布版本、已有会话或运行。
- 补充最小的创建/发布 Native 智能体入口，以便配置模型后进入现有对话流程；不扩展为完整智能体编辑器。

## 非目标
不接入沙箱、文件产物、知识库、MCP 或其他模型原生协议；不执行 PostgreSQL 专项验收或真实模型付费测试。

## 验收与确认
模拟供应商完成后端与浏览器验证，真实供应商由用户配置后另行验收。用户已明确确认提案，实施与验收记录见 verification.md。
