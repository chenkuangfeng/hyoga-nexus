# 工作台旧部门管理隔离

### ADDED Requirements

#### Requirement: 部门写页面由管理应用承接
工作台 SHALL 移除旧部门管理页面及设置导航，不再随设置页加载其组织读写实现；已迁移的部门维护由独立 admin 应用提供。

- **WHEN** 用户访问旧部门设置书签或内部旧快捷调用
- **THEN** 工作台展示迁移说明，不请求组织数据或提供组织写操作，有当前企业 admin 入口时提供显式管理应用链接，否则说明权限不足。

#### Requirement: 独立应用与兼容书签
迁移说明 SHALL 不自动跨应用导航。开发链接使用当前主机的管理应用端口，生产尊重应用 base；admin SHALL 继续校准身份及组织权限。

- **WHEN** 当前企业或服务端 entries 变化
- **THEN** 链接可见性随当前企业更新；旧书签不会因为移除导航而丢失迁移说明。

#### Requirement: 保留未完整迁移能力
清理 SHALL 保留尚未承接的实际能力，及共享空间、加入企业、企业切换和个人设置。退出企业与审计已分别由账户资料和管理端承接，旧企业信息/成员治理页可移除；其他管理配置和完整产物隔离仍为后续任务。

#### Requirement: 旧成员治理页面隔离
工作台 SHALL 移除旧成员治理页面、独占审批组件和设置导航，由管理端现有成员、审批及审计页面承接。

- **WHEN** 访问旧 members 书签或内部快捷调用
- **THEN** 展示迁移说明，按当前企业 admin 入口提供显式 members/audit 链接，不自动跨应用导航，也不读取或写入成员/邀请/申请/审计数据。
- **WHEN** 当前企业或入口变化
- **THEN** 链接可见性及时更新；共享空间成员管理、个人邀请/加入和退出企业不受清理影响。


### Requirement: 旧模型孤立实现清理与工具入口承接
工作台 SHALL 只通过 Nexus 模型页管理实际模型，删除孤立的 WeKnora 模型配置、编辑和调试实现及独占目录 store。聊天工具的模型草稿和 model_id 深链接 SHALL 由当前 Nexus 页面承接；草稿只预填无凭据字段，local 草稿明确提示不支持，不能静默连接旧 Ollama。共享模型选择器和资源编辑流程 SHALL 保留。

#### Scenario: 工具草稿打开模型表单
- **WHEN** 工具提供当前账号和企业的一次性远程模型草稿
- **THEN** 当前目录加载成功后打开表单，vllm/asr 映射 vision/speech，不预填密钥，不自动保存

#### Scenario: 切换身份中止旧写链
- **WHEN** 创建供应商或测试连接期间关闭页面或切换身份
- **THEN** 迟到响应失效，旧供应商结果不能继续在新企业创建模型，表单密钥被清空


### Requirement: 存储与向量库治理入口属于管理应用
工作台 SHALL 移除文件存储和向量库治理页面及常规导航，保留 storage/vectorstore 旧书签和知识库快捷调用的迁移说明。说明 SHALL 按当前身份的 Admin 入口提供显式链接，不自动跨应用跳转、不请求治理目录；无入口时提示联系管理员。知识库对已有存储和向量库的读取、选择及已有绑定 SHALL 保留。

#### Scenario: 打开旧配置书签
- **WHEN** 成员打开 storage 或 vectorstore 旧设置参数
- **THEN** 显示对应迁移说明，链接来自固定目标枚举，不挂载旧管理页面

#### Scenario: 切换企业后没有管理入口
- **WHEN** 当前企业身份不包含 Admin 入口
- **THEN** 说明保留但管理链接隐藏，不发起存储/向量库治理请求
