# 本地账号登录与企业微信绑定

## 状态

已实施并提交（`cc8a573`），**待用户确认**。本提案为事后补写：代码先于提案完成，违反了 AGENTS.md 中“涉及权限规则、持久化模型或 Runtime 行为变化须先提案并确认”的要求。确认前不归档本变更。

## 原因与范围

平台此前没有登录能力，Web 工作台无法区分使用者，角色与权限（`ff0cae0`、`36c5dca`）也无法落到具体成员上。本次补齐最小可用的身份入口：

- 空间管理员可创建本地密码账号，成员使用账号密码登录。
- 支持企业微信扫码登录，但仅限已绑定空间账号的企业微信成员。
- 已登录用户可在设置中绑定企业微信，或修改自己的密码。

不在本次范围内：注册流程、找回密码、多因素认证、企业微信通讯录同步、Runtime 与智能体行为变化。

## 变更

- 新增会话：服务端保存会话记录，Cookie 为 `HttpOnly`、`SameSite=lax`，默认 `Secure`；会话有效期 12 小时；库中只存摘要，不存原始令牌。
- 新增本地密码账号：scrypt 哈希，密码长度 10–256 字符；连续失败 5 次后锁定 15 分钟；失败信息统一为“用户名或密码错误”。
- 修改密码会吊销该用户全部会话。
- 新增企业微信登录与绑定：一次性 `state`，10 分钟有效，按用途（登录或绑定）区分，用后即失效；一个企业微信身份只能绑定一个空间账号。
- 新增管理员接口 `POST /api/v1/tenants/{tenant_id}/accounts`，需要 `members:manage` 权限。
- 新增 `create-owner` 子命令（`apps/api/src/nexus_api/cli.py` 的 `main(argv)`），用于部署时创建第一个 owner 账号。当前尚未注册为 pyproject 脚本入口，需要通过 Python 调用。
- 新增 Web 页面：登录页、我的账号页，角色管理页增加“添加账号”表单；`App.vue` 增加登录态检查与退出登录。
