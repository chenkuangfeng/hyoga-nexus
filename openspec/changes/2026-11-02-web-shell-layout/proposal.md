# Web 工作台布局：参考 WeKnora 的侧栏式结构

## 状态

草稿，待确认。确认"需要你决定的项"之后，才开始实施。

## 背景

当前 `apps/web/src/App.vue` 顶部是一排平铺按钮（对话工作台、用户设置、角色与权限、空间组织、组织与人员、会话查询、Native 与记忆、我的账号、平台能力、退出登录），页面通过 `location.hash` 切换。每个页面自己放置空间选择器与标题，视觉上缺少统一的导航层级，平台管理员与普通用户看到的入口也混在一起。

参考项目：WeKnora（`Tencent/WeKnora`，`frontend/src/components/menu.vue`、`views/platform/index.vue`）。它的结构是：左侧可折叠侧栏（Logo、搜索、空间切换、分组导航、底部用户区），右侧为主内容区；侧栏可拖拽调宽，窄屏收起。

## 范围

范围内：

- **外壳**：左侧可折叠侧栏 + 右侧主内容区，替代顶部平铺按钮。侧栏包含 Logo、全局搜索入口、空间选择器、分组导航、底部用户区（账号与退出）。
- **分组导航**：
  - 工作台：对话（侧栏内显示会话列表，见决定 3）。
  - 空间：空间组织、角色与权限、模型设置。
  - 个人：Native 与记忆、我的账号。
  - 平台管理（仅平台管理员可见）：组织与人员、会话查询、平台能力。
- **响应式**：宽度 ≥ 1024px 显示完整侧栏；768–1023px 侧栏折叠为图标列；< 768px 侧栏变为抽屉，由顶部按钮打开。
- **可访问性**：导航使用 `nav` 与 `aria-current`，可用键盘操作，焦点可见，遵守 `prefers-reduced-motion`。
- **保持**：Element Plus 组件库、现有的颜色与间距变量（`--surface`、`--border`、`--muted-text`、`--selected`）。不引入 WeKnora 的 TDesign 组件或其配色。

范围外：

- 不改变任何 API、权限判断、数据模型或 Runtime 行为。
- 不改变各页面的业务功能（只调整外壳与导航位置）。
- 不做深色主题。

## 需要你决定的项

1. **路由方式**：继续使用 hash 路由（改动最小，现有浏览器测试的地址不变），还是迁移到 `vue-router`（与 WeKnora 一致，但会改动全部页面入口与测试）。建议：先保留 hash，待页面稳定后再迁移。
2. **空间选择器位置**：放在侧栏顶部（全局切换，各页面不再重复放置），还是保留在各页面内。建议：放侧栏顶部，各页面去掉重复的空间下拉。
3. **会话列表位置**：对话页的会话列表移入侧栏（与 WeKnora 的对话历史一致），还是保留在对话页左栏。建议：移入侧栏，对话页只保留消息区。
4. **分组方式**：采用上面的四组，还是把"模型设置"归入"个人"。建议：按上面的四组，模型设置归入"空间"（模型与空间的可用范围相关）。
