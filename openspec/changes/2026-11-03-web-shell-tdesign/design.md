# 外壳、菜单与设置：功能清单与布局样式

来源：WeKnora（`Tencent/WeKnora`，MIT，本地源码 `/project/opensource/knowledge-base/WeKnora/frontend`）的 `src/components/menu.vue`、`src/stores/menu.ts`、`src/router/index.ts`、`src/views/settings/Settings.vue`、`src/config/integrations.ts`；本仓库 `apps/web/src/router/navigation.ts` 与各视图。

本文件只记录"外壳与导航"阶段的功能与布局。各分区的业务界面在实施对应路线图步骤时再读其源码并设计。WeKnora 分区的功能要点按分区名与源码文件名归纳，未逐个通读，实施前需要复核。

图例（处理方式）：**迁入**＝已有页面迁移到此；**占位**＝显示统一占位页，写明路线图步骤；**隐藏**＝不在导航中显示（待你确认，见 `proposal.md`）。

## 1. 整体布局

```
┌────────────┬─────────────────────────────────────────────┐
│ 侧栏        │ 主内容区（各页自带标题栏）                    │
│ 展开 260px  │                                             │
│ 折叠  48px  │  padding 24px（设置页见第 3 节）              │
│            │                                             │
└────────────┴─────────────────────────────────────────────┘
```

- 本阶段不设全局顶栏，页面标题在内容区顶部（与 WeKnora 的"侧栏 + 内容区"结构一致）。实施时以截图核对。
- 侧栏宽度：展开默认 260px，允许拖拽 200–400px，宽度存入 localStorage；折叠 48px；宽度过渡 0.25s（`prefers-reduced-motion` 下取消动画）。
- 参考 WeKnora：`menu.vue` 的 `aside_box` 默认宽度变量为 260px，折叠为 48px。

## 2. 侧栏（用户调整版）

外观元素（分组样式、图标、折叠按钮、拖拽、搜索）抄 WeKnora；布局结构按下列调整。自上而下：

| 区域 | 内容 | 说明 |
| --- | --- | --- |
| 品牌区（高 56px） | Logo、产品名；右侧折叠按钮 | 折叠时只显示 Logo 与展开按钮 |
| 新建会话 | 主按钮"新建会话"，右侧快捷键提示 | 唯一默认可见的功能入口，进入 `/chat` 新会话 |
| 最近会话 | 会话列表，按时间分组（"今天""更早"等，实施时对照 WeKnora 复核） | 会话多时在该区域内滚动；hover 显示操作（置顶、重命名、删除等，属于会话管理提案） |
| 更多功能（可折叠，默认收起） | 知识库、制品库、智能体、自动化、工具箱、组织（按权限显示） | 见第 2.1 节。这是对"默认只有新建会话"的理解，需你确认 |
| 搜索 | 搜索会话（打开现有 `SessionSearch`） | 可放在新建会话旁边，实施时与 WeKnora 的位置对照 |
| 底部用户区 | 用户名称（头像 + 名称 + 角色） | 点击弹出菜单，见第 2.2 节 |

### 2.4 响应式

| 宽度 | 侧栏 |
| --- | --- |
| ≥ 1024px | 展开（可折叠、可拖拽） |
| 768–1023px | 折叠为 48px 图标列，悬停显示名称（`t-tooltip`） |

### 2.5 可访问性

- 导航使用 `nav` 与 `aria-current="page"`；折叠按钮有 `aria-expanded` 与 `aria-controls`。
- 键盘：Tab 可达所有菜单项；Enter 进入；Esc 关闭抽屉；焦点环可见（使用 token 中的 focus 颜色）。
- 图标按钮必须有可访问名称（`aria-label` 或可见文字）。

## 3. 设置页布局

设置是独立页面，不弹窗。路由分三级：

| 级别 | 路由示例 | 呈现 |
| --- | --- | --- |
| 一级 | `/settings` | 设置首页：左侧分组导航 + 右侧分区入口（与 WeKnora 弹窗的导航结构一致） |
| 二级 | `/settings/models`、`/settings/members` 等 | 分区页：整页切换，内容区显示该分区的列表与设置 |
| 三级 | 编辑、新建、详情（如编辑模型、编辑成员角色） | **弹出**（抽屉或对话框，沿用 WeKnora 的 `ModelEditorDrawer` 等形式），地址栏可带查询参数但不新建页面 |

**返回**：一级与二级页面左上角有"返回"按钮。返回使用浏览器历史（`router.back()`）；若无历史（如直接打开深链），回到上一级（二级回一级，一级回对话页）。

```
┌────────────┬─────────────────────────────────────────────┐
│ 侧栏（同上） │ ← 返回   设置 / 模型管理                      │
│            │ ─────────────────────────────────────────── │
│            │ 分组标题（小字）  分区标题 + 说明                │
│            │ ▸ 分区名（选中）  内容（列表 / 表单）             │
│            │ ▸ 分区名          [新建] 等操作                 │
│            │ ...               三级：点击编辑 → 弹出抽屉      │
└────────────┴─────────────────────────────────────────────┘
```

设置页的侧栏仍显示最近会话与底部用户区，便于随时回到对话。设置页内的分组导航见第 3.1 节。

### 3.1 分组导航与分区

- 设置页内的左侧分组导航：分组标题小字（12px，次要文字色），分区项 `t-menu` 子项，只显示当前角色可见的分区。宽度实施时对照 WeKnora 截图确定（源码中弹窗的导航宽度未核对）。
- 内容区内边距参考 WeKnora `Settings.vue`：桌面 40px 48px，≤ 1024px 为 32px 36px，≤ 720px 为 16px。
- 分区标题 + 一行说明 + 内容。占位分区显示统一占位组件（第 6 节）。
- 地址 `/settings/:section`；无效分区重定向到默认分区（`general`，若当前角色不可见则取第一个可见分区）；角色不足时显示"无权限"提示（参考 WeKnora 的 `settings.roleDenied`）。

## 6. 占位页

所有"占位"项使用同一组件，内容固定：

- 标题（分区或菜单名）与一行说明（来自 i18n）；
- 状态："规划中"，并写明路线图步骤（如"路线图第 6 步：知识库"）；
- 返回入口：回到设置首页或对话页。

占位页不调用任何后端接口，不显示假数据。

## 7. 视觉样式

- **组件库**：`tdesign-vue-next`（与 WeKnora 同版本，^1.19.2）；图标 `tdesign-icons-vue-next` 0.4.4。全部页面迁移后移除 `element-plus`（见 `proposal.md` 第 4 项）。
- **颜色**：沿用 `apps/web/src/styles/tokens.css` 的语义 token（`--surface`、`--border`、`--muted-text`、`--selected` 等），在根节点把它们映射到 TDesign 的 CSS 变量（`--td-brand-color`、`--td-bg-color-container`、`--td-text-color-primary`、`--td-border-level-1-color` 等），不逐组件覆盖。
- **暗色**：依赖 `2026-11-03-dark-theme` 的调色板；TDesign 的颜色同样经由上述映射，切换时只改 token。
- **字体**：中文使用系统字体栈；沙箱环境缺少 CJK 字体，截图中的中文可能显示为方块，属于环境问题。
- **圆角、间距、字号**：先使用 TDesign 默认值，实施时与 WeKnora 截图逐页对比后微调，并把结果写回 token，不在组件里写死数值。
- **WeKnora 图标**：导航中的部分图标（如 `zhishiku`、`artifact`、`automation`）是 WeKnora 自有图标。可以复制 SVG 资源（保留 MIT 版权声明）或使用 TDesign 的近似图标；选择在实施时决定。

## 8. 状态与行为

- 空间切换：更改当前空间后，侧栏会话列表与设置页的可见分区同时刷新；不在空间切换时保留旧空间的数据。
- 角色变化：分区与菜单按当前空间角色即时过滤；角色不足时的地址显示"无权限"，不泄露分区内容。
- 加载：导航数据未加载完成前显示骨架，不渲染部分菜单（避免菜单闪烁），与 WeKnora 的 `settings` 策略一致。
- 侧栏折叠状态与宽度：存入 localStorage，刷新后保持。
