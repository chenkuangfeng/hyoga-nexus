# 设计

## 参考行为

WeKnora `frontend/src/views/chat/components/{usermsg,botmsg,AgentStreamDisplay}.vue` 为消息提供复制、分叉、回滚、知识收藏、产物、请求信息和追问状态；`frontend/src/components/Input-field.vue` 提供智能体/模式、联网、图片、附件、@资源、模型、推理强度与发送/停止。Nexus 保留相同的可用操作语义，但通过自身授权的 Session、Run、Knowledge 与 Artifact API 适配。

## Nexus 扩展

- 欢迎页只显示标题、错误状态与输入框。
- 分叉从选定消息创建同智能体的新会话，并只复制授权范围内且不晚于分叉点的会话消息；原会话不变。回滚按 WeKnora 语义删除分叉点之后的可见会话消息并将用户原文填回输入框；必须拒绝活动 Run，并记录审计。沙箱工作区若无法一致回滚，则该操作返回明确冲突，不报告成功。
- Run 请求扩展为有类型的选项：搜索模式、模型版本、推理级别、附件引用和知识资源引用。服务端将这些值纳入幂等摘要与不可变配置快照，按主体重新授权；Runtime 将可执行选项映射到模型请求与已绑定工具。附件采用平台私有存储句柄，聊天记录仅存引用和元数据，不把文件字节放入消息/事件。
- 加入知识库沿用现有文档创建/索引工作流，写入前选择用户可写的知识库，引用当前助手消息作为来源。
- 轨迹/请求详情读取持久化的模型请求快照。产物按钮切换到当前会话产物 Tab，并定位到该回复的产物。

## 风险与边界

回滚涉及会话消息与沙箱工作区的一致性，必须以事务或明确失败封闭；附件、模型和知识引用每次 Run 均重新授权。旧客户端不传选项时保持现有行为。现有消息、Run 和事件审计记录保留，不向客户端暴露其他用户数据。
