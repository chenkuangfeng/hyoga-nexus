# 规格：知识库

来源：`openspec/changes/2026-11-06-knowledge-base`（草案）。

## 需求

### R1 文档生命周期
- 同一库内上传内容相同的文件不产生新版本，返回已有文档并标注 `deduplicated`。
- 文档版本不可变；新版本在解析、分块、索引全部完成后才成为当前版本，之前检索只返回旧版本。
- 索引作业按阶段提交，进程中断后从最后提交的阶段继续，块不重复、不缺失；失败按退避重试，超过上限标记 `failed` 并记录原因，可手动重试。
- 删除库或文档后，下一次检索即不再返回其内容；块、向量与原文件由后台清理。

### R2 授权先于检索
- 每次检索先算出调用者此刻有权访问、状态正常的库及其当前文档版本，只在该集合内执行关键词与向量检索。
- 智能体只能检索其版本绑定的库；工具参数可以缩小范围，不能扩大。
- 撤权、删除、版本切换在下一次检索立即生效；无权内容不经任何通道（关键词、向量、降级）返回。

### R3 混合检索与降级
- 关键词与向量结果按加权 RRF 融合，分数在 [0, 1]；每条结果带通道名次、文档版本与索引版本。
- 向量通道不可用时只返回关键词结果，标注 `degraded` 及原因并写审计；降级不改变检索范围。

### R4 证据与引用
- 同一 Run 内进入模型上下文的块按首次出现编号 `[ID:n]`，重复出现沿用编号；挂起恢复后编号不变。
- Run 结束时，回答中已登记的 `[ID:n]` 生成指向文档版本与块的引用；未登记的编号不生成引用并产生 `knowledge.citation_invalid` 事件。
