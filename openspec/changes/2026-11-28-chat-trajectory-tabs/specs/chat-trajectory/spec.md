# 会话轨迹与产物标签

## ADDED Requirements

### 需求：会话页分标签浏览
工作台会话页必须提供对话、轨迹和产物三个顶层标签。产物列表必须在产物标签呈现，不再占用右侧常驻栏。嵌入式聊天维持紧凑对话布局。

#### 场景：查看会话产物
- **当** 用户打开已有会话并选择“产物”
- **那么** 页面在主内容区显示该会话产物、加载状态、失败重试或空状态

### 需求：检查 Run 执行轨迹
轨迹视图必须以会话中持久化的用户消息、助手消息和工具结果构成可选择的步骤列表，不能把 RunEvent 作为活动步骤的数据源。每个步骤可附带其直接关联的持久化模型请求快照、响应和用量；选中步骤后不得展示同组其他步骤的详情。

#### 场景：查看模型用量
- **当** 用户检查一次模型调用
- **那么** 页面区分请求输入 token 估算、供应商返回的单次实际 usage（如有）与 Run 累计 token
- **并且** 缺少供应商 usage 时，页面不得把估算值标成实际用量

### 需求：独立持久化模型请求轨迹
Runtime 必须将每次模型尝试写入独立轨迹记录，记录请求快照、响应或失败、单次 usage（若提供）、输入估算、Run 累计 token、状态与开始/完成时间。查询轨迹记录必须复用 Run 现有授权。

#### 场景：读取历史 Run
- **当** 旧版 Run 有会话消息但没有轨迹记录
- **那么** 轨迹仍显示可用的消息步骤
- **并且** 不从 RunEvent 伪造模型请求快照

### 需求：顶栏标签布局
非嵌入会话顶栏只显示靠左的三个标签“对话、轨迹、产物”，不显示会话标题和标题后操作；嵌入式聊天继续保持紧凑布局。

### 需求：逐轮活动轨迹
轨迹列表必须分别呈现当前会话各 Run 中已保存的用户消息、助手回复和工具调用/结果；没有工具调用时仍显示用户和助手活动。工具调用与结果按 call id 配对，点击活动可查看消息正文或工具参数、结果，以及关联的模型请求快照。不得以 RunEvent 推导轨迹活动。

#### 场景：无工具的模型回复
- **当** 一轮模型回复没有发起工具调用
- **那么** 记录表仍显示用户消息与助手回复
- **并且** 不显示虚构的工具活动

#### 场景：检查工具活动
- **当** 一轮包含工具调用及其执行结果
- **那么** 调用和结果显示为一个可选工具活动行
- **并且** 点击后可检查调用参数与持久化结果

### 需求：轨迹统计与行用量
轨迹顶部必须用紧凑统计方块显示请求次数、会话累计 Token 和缓存读取 Token；供应商返回输入 Token 时同时显示缓存占比。助手活动行在有供应商 usage 时显示该轮实际 Token，否则可显示输入估算并明确标记为估算。用户和工具活动不得伪造模型 Token。
列表按 Run 分组，显示每条活动的 Token 列；列宽固定，超长活动摘要以省略号裁切，详情面板保留完整内容。窄屏列表保持在容器内，不能撑破页面宽度。
每条用户输入必须作为该 Run 内活动的分组行，并支持折叠/展开。默认未选中活动时列表占满可用区域；选择活动后，右侧检查器以标签分类显示活动正文、工具/技能列表和模型请求。工具/技能先显示本地化名称，展开后查看调用参数与结果。数据行固定为 20px 高，超出内容省略；列表在自身区域滚动。Run ID 不占单独的数据行；Run 边界使用 1px 中性色细线呈现。用户输入行需作为分组标题突出显示，子活动缩进并显示中性层级线，折叠图标方向清楚可辨。
右侧检查器必须以当前选中的消息或工具步骤为作用范围，只显示该步骤内容及其直接关联的模型请求和用量；不得汇总同一用户输入分组下的其他步骤。工具步骤默认展示该工具的参数与结果；无关联数据的标签不显示。
工具调用活动必须通过模型响应中的调用 ID 与持久化工具结果配对，不依赖 Run 轮次从 1 开始。模型请求快照中出现常驻画像或记忆召回 `<user_memory>` 内容时，按 Run 去重后作为记忆活动展示；它不是工具调用，也不从 RunEvent 推导。

#### 场景：检查单个工具步骤
- **当** 用户选择某个工具调用步骤
- **那么** 右侧只显示该调用的参数、执行结果和发起该调用的模型请求及用量
- **并且** 不显示同一用户输入分组中其他工具或模型请求的详情

#### 场景：检查用户消息
- **当** 用户选择一条用户输入
- **那么** 右侧显示该条输入正文
- **并且** 不显示与该消息无直接关联的工具或模型请求标签

#### 场景：展示模型用量
- **当** 供应商为模型请求返回 usage
- **那么** 顶部统计缓存读取量，助手活动行显示该轮输入与输出 Token 合计
- **并且** 供应商未提供缓存数据时，缓存统计显示不可用状态而不是 0% 命中
