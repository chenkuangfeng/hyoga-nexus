## ADDED Requirements

### Requirement: 双应用浏览器回归入口
Web 工程 SHALL 提供可重复运行的 Playwright 命令，分别测试工作台和企业管理应用，使用实际应用与界面组件。浏览器环境 SHALL 模拟认证与业务接口，未声明请求 SHALL 使测试失败，测试产物 SHALL 不进入版本控制。

#### Scenario: 管理应用配置保存
- **WHEN** 运行管理应用浏览器项目
- **THEN** 浏览器验证独立登录、解析配置保存前确认、已有密钥与 false 保留，以及窄屏无页面横向溢出

#### Scenario: 工作台兼容入口
- **WHEN** 运行工作台浏览器项目并打开旧 parser 书签
- **THEN** 显示独立管理应用的显式迁移链接，不请求治理配置，不自动跳转

#### Scenario: 验证边界
- **WHEN** 模拟接口浏览器回归通过
- **THEN** 报告明确其为前端回归，不将真实 API、生产构建或尚未覆盖的业务标记为完成

### Requirement: 完整工程门禁与生产预览
Web 工程 SHALL 提供覆盖全部业务源码和 Vue 模板的严格类型检查，以及串行产出两个独立应用的生产构建命令。实际构建模块图 SHALL 拒绝另一应用的源码。预打包浏览器依赖 SHALL 使用同源资源并共享唯一 Vue 运行时，保留原有导出、格式和语言支持。

#### Scenario: 严格类型工程
- **WHEN** 执行根包类型检查命令
- **THEN** 原 tsconfig 的全部业务文件和模板均由原生 vue-tsc 检查，循环依赖保留在同一引用工程，生成声明保留原包的依赖解析上下文，不跳过模板或放宽严格选项

#### Scenario: 实际生产资产执行
- **WHEN** 完整构建后执行生产预览浏览器命令
- **THEN** 两应用使用实际 dist 完成既有界面回归，并执行 Mermaid、PDF worker、高亮、公式和表格资源，验证 VueOffice 模块加载；明确模拟 API 与真实服务验收的边界
